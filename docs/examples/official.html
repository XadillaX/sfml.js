SFML official examples ​

JavaScript ports of 24 SFML examples, covering graphics, native windows, input, audio and networking. Android is not ported yet.

All examples · Build requirements

Quick start ​

From the repository root:

sh
npm ci
cd examples/official
node tennis/Tennis.cjs

All commands below run from examples/official. Each script loads its own resources. Graphical examples need a display and OpenGL window support.

Browse: Graphics · Platform integration · Input and events · Audio · Networking

Platform integration ​

ExamplePlatformDependencies
Window / OpenGLmacOS, Linux, Windows@wettstein/nodegl, installed by the root npm ci
X11Linux with X11x11 and @wettstein/nodegl, installed by the root npm ci
CocoamacOSnpm ci --prefix cocoa --ignore-scripts
Win32Windows x64, Node.js 20+npm ci --prefix win32 --ignore-scripts
VulkanLinux x64 (X11) or Windows x64, Node.js 20+npm ci --prefix vulkan --ignore-scripts

Building nodegl requires CMake, a C++ compiler and OpenGL development libraries (libgl1-mesa-dev on Linux). Vulkan also needs a Vulkan loader and a driver supporting 4× anisotropic filtering.

PreviewExample

Window

A rotating six-colored cube in an OpenGL window

Controls · resize by dragging the window border; Esc or window close exits

node window/Window.cjs

OpenGL

SFML background and text with a textured OpenGL cube

Controls · mouse moves the cube, Enter toggles mipmapping, Space toggles sRGB, Esc exits

node opengl/OpenGL.cjs

Vulkan

A rotating textured cube rendered with Vulkan

Controls · mouse moves the cube, drag the window border to resize, Esc or window close exits

node vulkan/Vulkan.cjs

Cocoa

Native macOS controls with an embedded SFML view

Controls · Update or Enter applies text; Visible toggles the logo; the dial rotates it; Color selects the background; Up/Down scales it; close, Cmd+Q or Ctrl+C exits

node cocoa/Cocoa.cjs

Win32

A native Windows window with two animated SFML views and a Quit button

Controls · Quit, window close or Ctrl+C exits

node win32/Win32.cjs

X11

Two embedded SFML windows with cubes rotating at different speeds

Controls · any key, window close or Ctrl+C exits

node X11/X11.cjs

Networking ​

ExampleRun
HTTP
Interactive HTTP GET with redirects		node http/Http.cjs
FTP
Interactive FTP client, port 21		node ftp/Ftp.cjs
SFTP
Interactive SFTP client; confirm the host fingerprint, then authenticate		node sftp/Sftp.cjs
Sockets
TCP, TLS or UDP greeting exchange, port 50001		node sockets/Sockets.cjs
VoIP
TCP voice capture, playback and replay, port 2435		node voip/VoIP.cjs

For sockets and VoIP, run the entry point in two terminals: select server in one and client in the other. Use 127.0.0.1 for a local exchange.
