RmlUi examples ​

Run RmlUi documents in native SFML windows. Start with the counter, then explore themes, draggable windows, templates and visual test pages.

Prerequisites ​

Run all commands from the monorepo root. Bootstrap installs dependencies and builds the packages. A display and OpenGL are required; on macOS the native build also needs Xcode Command Line Tools and CMake. See the quick start.

sh
node tools/bootstrap.cjs

After editing RmlUi TypeScript sources, run npm run build:ts --prefix packages/sfml.js-rmlui. Examples use the locally built package.

The launcher reads RmlUi 6.3's bundled resources under the package's third_party/rmlui directory. List all entries:

sh
node packages/sfml.js-rmlui/examples/official.cjs --list

Counter

JavaScript event listeners, external RML, blur, drop shadow and rounded clipping

RML · RCSS

Themes and variables

Theme switching, accent colors and hover styles

node packages/sfml.js-rmlui/examples/official.cjs variables

Controls: 1 selects dark, 2 light, 3 high contrast, R a random accent and C resets the accent. Escape exits. Mission buttons demonstrate hover styles only; upstream does not attach click actions.

The original stylesheet uses fixed px lengths. This sample keeps a 1024 × 768 framebuffer on Retina as well, with highDpi: false, matching the upstream window. F8 toggles Debugger; Ctrl +/-/0 adjusts the shell's display density.

Upstream application

Invaders

Run the original C++ game, menus, decorators and high-score data model.

node packages/sfml.js-rmlui/examples/official.cjs invaders

Left/Right moves, Space fires, Escape opens the pause menu and F8 toggles Debugger. Use the original menus to restart or exit.

Build the package first; the game module is produced in the same build directory. Loading needs no compiler and is verified on macOS, Linux and Windows. Comparison with the original native game runs on macOS; Linux and Windows game comparisons remain unverified.

Scores use application data storage. --scores-file /absolute/path/scores.txt selects an existing parent directory. --frames 8 --exercise starts a bounded game.

Upstream VisualTests · Renderer coverage

Coverage and verification ​

The gallery includes all 20 official applications and tutorials, eight binding examples and a browser for all 113 upstream VisualTests pages. Every gallery entry has a run command, source link, interaction notes and a native screenshot; all 29 screenshots are present.

The RmlUi runtime suites pass on macOS, Linux and Windows. Native SFML/GL3 effect comparisons and original-game comparisons run on macOS. The VisualTests launcher is a preview; separate comparison records cover 113 pages and 25 interactive pages. Four content checks and two interaction checks also fail in the pinned upstream renderer. Those records report zero binding regressions, while full VisualTests and independent whole-project acceptance remain open.

The macOS system IME item is closed under the existing acceptance decision, with observed preedit, commit, cancellation and caret coordinates retained in the desktop record. Hardware keyboard input, reliable fresh-process repeats and candidate-panel placement were not verified. Linux and Windows system IME remain unverified.
