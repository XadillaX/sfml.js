RmlUi 示例 ​

在原生 SFML 窗口中运行 RmlUi 文档。从计数器开始，再体验主题变量、拖动窗口、模板和视觉测试页面。

运行准备 ​

以下命令均在 monorepo 根目录执行。首次运行 bootstrap 安装依赖并构建各包。需要显示环境和 OpenGL；macOS 原生构建另需 Xcode Command Line Tools 和 CMake。详见快速开始。

sh
node tools/bootstrap.cjs

修改 RmlUi TypeScript 源码后，执行 npm run build:ts --prefix packages/sfml.js-rmlui。示例使用本地构建的包。

启动器读取包内 third_party/rmlui 下 RmlUi 6.3 的内置资源。列出全部入口：

sh
node packages/sfml.js-rmlui/examples/official.cjs --list

示例 ​

计数器

JavaScript 事件监听器、外部 RML、模糊、投影和圆角裁剪

node packages/sfml.js-rmlui/examples/demo.cjs

操作：点击 Increment 更新计数。关闭窗口退出。

RML · RCSS

主题与变量

主题切换、强调色和悬停样式

node packages/sfml.js-rmlui/examples/official.cjs variables

操作：1 切换深色、2 浅色、3 高对比度， R 随机强调色，C 重置强调色，Escape 退出。 任务按钮只展示悬停样式，上游没有注册点击行为。

原始样式表使用固定 px 长度。此示例设置 highDpi: false，Retina 下也保持 1024 × 768 帧缓冲， 与上游窗口尺寸一致。 F8 切换 Debugger；Ctrl +/-/0 是 Shell 的密度快捷键。

上游 RML

拖动教程

可移动和调整大小的物品栏窗口

node packages/sfml.js-rmlui/examples/official.cjs drag

操作：用鼠标移动两个窗口并调整大小，Escape 退出。

此处移植的是教程窗口设置，与上游 basic/drag 应用不同。

上游 RML

模板教程

九宫格纹理与外部模板

node packages/sfml.js-rmlui/examples/official.cjs template

操作：查看使用模板装饰的窗口，Escape 退出。

操作：查看加载后的文档，Escape 退出。 此入口未接入其他上游演示的应用动作。

Invaders

运行原始 C++ 游戏、菜单、装饰器和高分榜数据模型。

node packages/sfml.js-rmlui/examples/official.cjs invaders

左右键移动，空格开火，Escape 打开暂停菜单，F8 切换 Debugger。通过原始菜单重开或退出。

先构建包；游戏模块在同一个构建目录中生成，加载时无需编译器。macOS 已验证；Linux 和 Windows 实际执行仍待验证。

高分保存到应用数据目录。--scores-file /absolute/path/scores.txt 指定已有父目录中的文件。--frames 8 --exercise 启动限帧游戏。
