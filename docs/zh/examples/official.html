SFML 官方示例 ​

SFML 官方示例 的 JavaScript 移植，包含图形、原生窗口、输入、音频和网络等 24 个示例。Android 尚未移植。

全部示例 · 构建要求

快速开始 ​

在仓库根目录执行：

sh
npm ci
cd examples/official
node tennis/Tennis.cjs

下文命令均在 examples/official 中运行，各脚本会自动加载所需资源。图形示例需要显示服务与 OpenGL 窗口支持。

浏览：图形 · 平台集成 · 输入与事件 · 音频 · 网络

平台集成 ​

示例平台依赖安装
Window／OpenGLmacOS、Linux、Windows根目录的 npm ci 会安装 @wettstein/nodegl
X11带 X11 显示服务的 Linux根目录的 npm ci 会安装 x11 和 @wettstein/nodegl
CocoamacOSnpm ci --prefix cocoa --ignore-scripts
Win32Windows x64、Node.js 20+npm ci --prefix win32 --ignore-scripts
VulkanLinux x64（X11）或 Windows x64、Node.js 20+npm ci --prefix vulkan --ignore-scripts

编译 nodegl 需要 CMake、C++ 编译器和 OpenGL 开发库，Linux 可安装 libgl1-mesa-dev。Vulkan 还需要 Vulkan 加载器和支持 4 倍各向异性过滤的驱动。

Window

OpenGL 窗口中的六色旋转立方体

OpenGL

SFML 背景、文字与 OpenGL 纹理立方体混合绘制

操作 · 鼠标移动立方体，Enter 切换 mipmap，Space 切换 sRGB，Esc 退出

node opengl/OpenGL.cjs

Vulkan

Vulkan 渲染的旋转纹理立方体

操作 · 鼠标移动立方体，拖动窗口边缘调整大小，Esc 或关闭窗口退出

node vulkan/Vulkan.cjs

Cocoa

macOS 原生控件与嵌入的 SFML 视图

操作 · Update 或 Enter 更新文字，Visible 切换标识显隐，旋钮控制旋转，Color 选择背景色，Up／Down 缩放；关闭窗口、Cmd+Q 或 Ctrl+C 退出

node cocoa/Cocoa.cjs

Win32

Windows 原生窗口中的两个 SFML 动画视图与 Quit 按钮

操作 · Quit、关闭窗口或 Ctrl+C 退出

node win32/Win32.cjs

X11

两个嵌入的 SFML 窗口，以不同速度旋转的立方体

操作 · 任意键、关闭窗口或 Ctrl+C 退出

node X11/X11.cjs

Sound effects

九种音效

操作 · 左／右切换，鼠标调整，上／下选择衰减模型或波形，Space 旁路 DSP，F1 切换输出设备

示例与操作运行
Sound
播放 WAV 音效及 OGG、FLAC、MP3 音乐		node sound/Sound.cjs
Sound capture
选择设备与采样率，录音后播放或保存		node sound_capture/SoundCapture.cjs
Sound device
设备通知、自动路由与设备丢失恢复；Ctrl+C 退出		node sound_device/SoundDevice.cjs

网络 ​

示例与操作运行
HTTP
带重定向处理的交互式 HTTP GET		node http/Http.cjs
FTP
交互式 FTP 客户端，端口 21		node ftp/Ftp.cjs
SFTP
交互式 SFTP 客户端；先确认主机指纹，再登录		node sftp/Sftp.cjs
Sockets
TCP、TLS 或 UDP 消息交换，端口 50001		node sockets/Sockets.cjs
VoIP
TCP 语音采集、播放和回放，端口 2435		node voip/VoIP.cjs

sockets 和 VoIP 各开两个终端，分别选择服务端、客户端；本机测试填写 127.0.0.1。
