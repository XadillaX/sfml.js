安装与运行

Node.js 20.5+ · 带音频输出的图形桌面 · 原生构建要求

在存放项目的目录中克隆仓库，再进入游戏目录运行：

sh
git clone https://github.com/XadillaX/super-mario-kart-sfml.js.git
cd super-mario-kart-sfml.js
npm install
npm start

npm start 编译到 dist/ 后启动游戏。Python 赛道制作工具为可选项，游玩不需要安装。

Controls 和 Settings 菜单可调整按键、音量与分辨率。

赛道、项目来源与许可展开收起

super-mario-kart-sfml.js 使用 TypeScript + sfml.js 移植 vmbatlle/super-mario-kart。原版使用 C++ 和 SFML 2.5.1 编写；移植版的 54 个 TypeScript 模块沿用上游源码目录结构，保留 Mode 7 渲染、玩法、AI 与素材。

依赖固定为 sfml.js@1.0.0-rc.2 和 typescript@7.0.2。

五条赛道分别为 Donut Plains 1、Mario Circuit 2、Ghost Valley 1、Bowser Castle 1 和 Rainbow Road。代码采用 GPL v3；角色、图像与音乐归 Nintendo 所有。这是非官方的教育用途同人项目。

推荐 Node.js 22 · Python 与 C++20 编译器 · 带音频输出的图形桌面

安装已发布的播放器，启动内置游戏：

sh
npm install -g play-nes
nes croom

打开有权使用的本地 ROM：

玩一局打砖块 ​

在 monorepo 根目录执行一次 node tools/bootstrap.cjs，再 cd packages/sfml.js。下方命令均从该包目录运行，修改源码后在包内执行 npm run build。图形示例需要显示环境和 OpenGL，独立项目按各自说明安装。

breakout.cjs 包含砖块碰撞、三条生命、计分与胜负状态。方向键左／右或 A／D 移动挡板，Space 发球或重新开始，P 暂停，Esc 退出。交互模式下失去焦点会暂停。

npm run demo:breakout 构建并启动游戏。macOS／Linux 可用以下命令复现游戏截图：

sh
SFML_DEMO_SNAPSHOT=/tmp/sfml-breakout.png \
  node examples/breakout.cjs --autoplay --frames=1500

截图保存最后一帧的真实原生画面。--autoplay 自动控制挡板，--frames 限制运行帧数。node examples/breakout.cjs --self-test 无需打开窗口即可检查游戏逻辑。

node-sfml-demos ​

node-sfml-demos 包含使用 sfml.js 实现的 Bomberman、Breakout、Tetris、Doodle Jump 和 Arkanoid。

在存放项目的目录中克隆这个独立仓库，再进入各游戏目录安装依赖并启动。以 Bomberman 为例：

sh
git clone https://github.com/XadillaX/node-sfml-demos.git
cd node-sfml-demos/bomberman
npm install
node index.js

游戏目录、操作方式与上游 C++ 源码见 仓库 README。安装同样需要满足 原生构建要求。

使用 Node.js 22、Python 3 与 C++20 工具链。在各游戏目录内执行 npm install，再运行 node index.js。部分游戏共享字体和纹理，请保留完整仓库。各游戏固定依赖 sfml.js@1.0.0-rc.2，本页不会升级它们。所有游戏均支持关闭窗口，Bomberman 还会使用音频。Tetris、Doodle Jump 和 Arkanoid 保留原型中尚未完善的游戏逻辑。

Bomberman

格子场地中的双人炸弹人。

操作 · 玩家一：WASD 移动，左 Ctrl 放炸弹。玩家二：方向键移动，Space 放炸弹。鼠标操作菜单，Esc 暂停／继续。

在此目录运行：node-sfml-demos/bomberman/

npm install
node index.js

在此目录运行：node-sfml-demos/breakout/

16 个 ClojureScript 游戏 ​

16-sfml.js-games-ported Fork 自 jsyqrt/games。原版 16 个游戏就是使用 C++ 和 SFML 编写的；这个 Fork 将它们全部迁移为 ClojureScript + sfml.js，保留原目录结构、素材、游戏逻辑和操作方式。

游戏通过 nbb 在 Node.js 上运行，无需 JVM 或单独编译。在存放项目的目录中克隆游戏仓库，再从仓库根目录启动：

sh
git clone https://github.com/XadillaX/16-sfml.js-games-ported.git
cd 16-sfml.js-games-ported
npm ci
npx nbb "01 Tetris/main.cljs"

需要 Node.js 20.5+、满足 原生构建要求 的环境，以及支持 OpenGL 窗口的图形会话。依赖固定为 sfml.js@1.0.0-rc.2 和 nbb@1.6.214。各脚本按自身目录定位资源。

01 · Tetris（俄罗斯方块）

方块下落与消行

操作 · 左／右移动，上旋转，下加速下落

npx nbb "01 Tetris/main.cljs"

02 · Doodle Jump（涂鸦跳跃）

随画面滚动在平台间跳跃

操作 · 左／右移动，自动跳跃

npx nbb "02 Doodle Jump/main.cljs"

03 · Arkanoid（打砖块）

用弹球消除砖块

操作 · 左／右移动挡板

npx nbb "03 Arkanoid/main.cljs"

04 · Snake（贪吃蛇）

收集食物并增长

操作 · 方向键改变方向

npx nbb "04 Snake/main.cljs"

05 · Minesweeper（扫雷）

揭开格子并标记地雷

操作 · 左键揭开，右键插旗

npx nbb "05 Minesweeper/main.cljs"

06 · Fifteen-Puzzle（十五数码）

4 × 4 滑块拼图

操作 · 点击空格旁的方块进行移动

npx nbb "06 Fifteen-Puzzle/main.cljs"

07 · Racing（俯视赛车）

与电脑控制的赛车同场竞速

操作 · 上加速，下刹车／倒车，左／右转向

npx nbb "07 Racing (Top Down)/main.cljs"

08 · Outrun（伪 3D 赛车）

透视道路、弯道与路边景物

操作 · 左／右转向，上／下前进／后退，Tab 加速，W／S 调整相机高度

npx nbb "08 Outrun/main.cljs"

09 · Xonix（圈地）

躲避敌人并圈占领地

操作 · 方向键移动，Esc 重置棋盘

npx nbb "09 Xonix/main.cljs"

10 · Bejeweled（宝石消除）

交换相邻宝石组成连线

操作 · 依次点击两颗相邻宝石交换

npx nbb "10 Bejeweled/main.cljs"

11 · NetWalk（管道连接）

将计算机连接到服务器

操作 · 点击管道旋转

npx nbb "11 NetWalk (Pipe Puzzle)/main.cljs"

12 · Mahjong Solitaire（麻将接龙）

移除可选的相同麻将牌对

操作 · 左键选择配对，右键撤销

npx nbb "12 Mahjong Solitaire/main.cljs"

13 · Tron（光轮摩托）

双人光轮摩托轨迹对抗

操作 · 方向键控制红方，W／A／S／D 控制绿方

npx nbb "13 Tron/main.cljs"

14 · Chess（国际象棋）

可拖动棋子的棋盘与外部 Stockfish 引擎

操作 · 拖动棋子，Space 请求引擎走棋，Backspace 撤销

npx nbb "14 Chess/main.cljs" /path/to/stockfish

需自行安装适合当前系统的 Stockfish 可执行文件，并传入解压后的可执行文件路径。仓库不附带引擎。Windows 也可把 stockfish.exe 放在 main.cljs 旁，不传参数即可启动。

15 · Volleyball（排球）

使用 Box2D 物理的双人排球

操作 · 红方左／右移动、上跳跃；绿方 A／D 移动、W 跳跃

npx nbb "15 Volleyball/main.cljs"

游戏仓库根目录的 npm ci 会安装 box2dweb@2.1.0-b。

16 · Asteroids（小行星）

驾驶飞船击碎小行星

操作 · 左／右旋转，上推进，Space 开火

npx nbb "16 Asteroids/main.cljs"

Chess 需要自行下载适合当前系统的 Stockfish 可执行文件，按表中命令传入路径。Volleyball 使用的 box2dweb 由 npm ci 安装。关闭游戏窗口即可退出。截图、源码和操作说明见 游戏展示。
