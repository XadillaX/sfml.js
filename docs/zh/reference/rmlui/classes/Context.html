    Context

    绑定到单个 sfml.js 渲染窗口的 RmlUi 上下文。

    备注

    通过 createContext 获取已注册实例，或通过 Factory.instanceContext 获取独立自有实例。原生上下文持有已挂接文档； Context.remove 或 shutdown 后不可继续使用相关包装器。

    processEvent

    • processEvent(event: Event<(keyof EventPayloads)> | EventData): boolean

      将 sfml.js 窗口事件转交给 RmlUi 上下文。

      参数

      event
      Event<(keyof EventPayloads)> | EventData

      sfml.js 事件对象或事件数据。

      返回值

      boolean

      上游传播或交互结果；忽略的事件返回 true。

      备注

      键盘、文本和滚轮返回传播状态；鼠标、触摸返回是否未与元素交互。 坐标使用物理像素。键盘修饰键来自事件快照，指针修饰键来自实时键盘状态。 触摸事件转为单条 TouchList。系统键在 macOS 映射为 LMETA/RMETA， 其他平台为 LWIN/RWIN。TextEntered 将 CR 转为 LF 并跳过其他控制字符。 尺寸变化事件自动更新尺寸与密度。
