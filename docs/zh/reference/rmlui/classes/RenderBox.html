    RenderBox

    独立的 Rml::RenderBox，包含可写原生数值视图。

    备注

    元素查询返回副本。视图只保活原生数值，在元素销毁、包装器回收及运行时 关闭后仍可访问。原生查询会拒绝共享字段中的非有限值。
