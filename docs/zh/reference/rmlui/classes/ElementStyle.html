    ElementStyle

    带检查的元素自有 Rml::ElementStyle，保留原生层叠与脏状态。

    备注

    类与伪类 setter 直接遵循 ElementStyle，变化后显式调用 updateDefinition。 查询返回自有快照。高频数值操作使用 ElementCommandBuffer 的样式操作码和 共享数据平面；常规布局计算留在原生。销毁元素或关闭运行时后全部操作失效。

    computeValues

    • computeValues(
          values: ComputedValues,
          parentValues: null | ComputedValuesView,
          documentValues: null | ComputedValuesView,
          valuesAreDefaultInitialized: boolean,
          dpRatio: number,
          viewportDimensions: VariantVector2,
      ): Set<PropertyId>

      计算到独立原生值并消费元素真实脏集合。

      参数

      values
      ComputedValues

      关联本元素的可写值。

      parentValues
      null | ComputedValuesView

      已计算的父元素值或 null。

      documentValues
      null | ComputedValuesView

      已计算的文档值或 null。

      valuesAreDefaultInitialized
      boolean

      输出仍使用原生默认值。

      dpRatio
      number

      有限正数密度比率。

      viewportDimensions
      VariantVector2

      有限原生视口尺寸。

      返回值

      Set<PropertyId>

      返回已消费的脏编号，继承依赖传播到子元素。

      备注

      按父先子后执行。只写独立输出，不调用 OnPropertyChange 或更新布局。 后续 Context.update 前用 dirtyProperty 重新标记返回的全部编号，使原生 UpdateProperties 将待更新值应用到实时布局。
