    Stream

    使用原生内存、文件或同步 JS 存储的受检查 Rml::Stream。

    备注

    shutdown 使所有包装对象失效。返回的字节数组均为独立副本。 字节批次和内存大小须为 [0, 2147483647] 范围内的整数。
