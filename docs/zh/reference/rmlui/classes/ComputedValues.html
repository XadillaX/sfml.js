    ComputedValues

    关联存活元素的独立 Rml::ComputedValues 存储。

    备注

    构造器使用上游默认值；copyInherited/copyNonInherited 复制原生字段分组， 不替换关联元素。fontFamily、cursor、animation、transition、transform 和 flex 关键字等 getter 读取关联元素。赋值只修改独立对象。元素销毁或运行时关闭后 全部访问失效。Element.getComputedValues 返回实时只读视图；查询前调用 Context.update 更新布局。
