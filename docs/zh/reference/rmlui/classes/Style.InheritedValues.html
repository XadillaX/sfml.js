    Style.InheritedValues

    继承的文本、颜色和输入属性的独立存储。

    备注

    使用上游默认值，独立于 DOM 和运行时。数值视图仅保活此结构， 颜色 getter 返回副本；非空字体句柄要求当前运行时世代有效。
