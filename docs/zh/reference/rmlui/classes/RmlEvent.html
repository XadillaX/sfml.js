    RmlEvent

    RmlUi 事件快照，原生传播控制仅在当前回调期间有效。

    备注

    每个监听器收到独立快照，包含投影后的坐标。保存的字段可继续读取。 回调返回后，即使其他监听器仍在执行，传播状态和停止方法也会抛出异常。 id 标识事件类型，并非某次派发的唯一编号。

    getParameter

    • getParameter<const T extends VariantConversionDefault>(
          name: string,
          defaultValue: T,
      ): VariantResult<T>

      Rml::Event::GetParameter 类型转换，原生事件有效期间可用。

      类型参数

      • const T extends VariantConversionDefault

        由默认值选择的原生转换类型。

      参数

      name
      string

      原生参数名。

      defaultValue
      T

      选择 T 的非空自有 Variant。

      返回值

      VariantResult<T>

      原生转换结果；参数缺失时返回默认值。

      备注

      读取实时投影参数，不受 JS 快照修改影响。number 选择 double； BigInt 选择 int64，超过 INT64_MAX 时选择 uint64。遵循 RmlUi 规则， 非数字字符串转换为 number 时得到 0。整数溢出抛出异常； scriptinterface 样本读取受保护的 Element、Context 或 Event 指针； 原生目标失效时返回 null。 向量和颜色返回副本；需要保留原始值时使用 parameters。
