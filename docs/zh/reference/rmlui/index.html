    sfml.js-rmlui · 概览

    初始化、字体、事件传递与帧渲染。 RML 加载、元素属性与原生对象生命周期。 事件数据副本与 JavaScript 监听器签名。

    运行时与上下文

    初始化、字体、事件传递与帧渲染。

    initialise

    使用 SFML 支撑的系统接口与渲染接口初始化 RmlUi。

    createContext

    创建命名的 RmlUi 上下文。

    Context

    绑定到单个 sfml.js 渲染窗口的 RmlUi 上下文。
