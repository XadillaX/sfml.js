    受保护onProcessSamples

    • onProcessSamples(samples: Int16Array): boolean | Promise<boolean>

      在对象所属 JS 线程串行处理交错的 16 位 PCM，长度单位为样本而非帧。 Native 视图仅在本次同步或异步回调结束前有效；false 异步停止采集。 默认将传入样本追加到 Native 聚合器；可修改后调用 super，不调用则不保存。

      参数

      samples
      Int16Array

      返回值

      boolean | Promise<boolean>
      源码与继承
      • 定义于 src/audio/sound-buffer-recorder.ts:76

    受保护onStart

    • onStart(): boolean | Promise<boolean>

      在对象所属 JS 线程开始采集前调用；支持同步或异步返回，false 拒绝采集。 默认清空本次 Native PCM 聚合和录音缓冲区，不访问麦克风。

      返回值

      boolean | Promise<boolean>

    受保护onStop

    • onStop(): void | Promise<void>

      在设备停止且已交付回调结束后，于对象所属 JS 线程调用一次，支持异步完成。 拒绝、取消和异常同样触发；默认将已通过 super 追加的 PCM 完成为 SoundBuffer。

    start

    • start(sampleRate?: number): Promise<boolean>

      异步初始化采集会话，默认 44100 Hz；已采集、拒绝或启动失败返回 false。 不可在子类回调内部重新启动；应在外部等待 stop() 后再开启下一会话。

      参数

    • stop(): Promise<void>
