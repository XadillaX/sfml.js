ImGui 指南 ​

使用 sfml.js-imgui，在 SFML 窗口中构建调试面板、场景检查器和原生编辑器控件。本指南从第一段帧循环出发，逐步加入状态编辑、表格、文本输入、字体和自定义渲染。

当前源码面向 Dear ImGui 1.91.9b 和 imgui-sfml 3.0，示例使用 JavaScript 与 SFML 3.1 API。需要 JavaScript 和 SFML 窗口基础，不要求 C++ 知识。

学习路径 ​

章节学习结果
快速开始完整计数器、帧生命周期、输入捕获与安全退出
控件与状态持久编辑状态、唯一 ID、实时场景检查器
布局与工具面板表格、菜单、确认弹窗与作用域配对
文本输入与回调UTF-8 编辑、回调契约、列表与曲线
字体与样式字体图集、CJK 覆盖、间距、颜色与 DPI
渲染与多窗口场景合成、绘制列表与按窗口划分的资源所有权
API 使用指南查找准确签名、重载和生命周期约束

实践章节提供完整可运行源码，说明局部代码应放在哪里，并列出预期结果。各章提供英文、中文、日文、韩文版本。

选择可运行示例 ​

在 monorepo 根目录执行一次 bootstrap，再启动示例：

sh
node tools/bootstrap.cjs
node packages/sfml.js-imgui/examples/demo.cjs
  • 控件演示：浏览 Dear ImGui 自带的控件和布局。
  • 场景检查器：编辑运动圆形的大小、颜色与速度。
  • 工作台：组合文本编辑、对象选择、表格、模态弹窗和耗时曲线。

理解包的职责 ​

ImGui 导出控件、枚举、回调包装和原生句柄操作；SFML 负责原生窗口集成、事件转发和帧提交。getFontAtlas、getStyleColors 等是顶层导出。

应用值由 JavaScript 持有，可写原生标量参数使用类型化数组。IO、样式视图、字体和绘制列表具有原生所有者及有效期。各章会在使用相应功能时解释边界，准确契约见 API 参考。
