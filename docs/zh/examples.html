从这里开始 ​

Süper Mario Kart

TypeScript 赛车游戏，包含 Mode 7 渲染、8 名车手和 5 条赛道。可挑战 Grand Prix 或单场比赛，与 7 名 AI 对手竞速。

查看玩法与运行说明

play-nes

提供原生图形与音频的桌面 NES 模拟器。可直接游玩内置的 Concentration Room，也可载入有权使用的本地 ROM。

查看玩法与运行说明

Breakout · 打砖块

本仓库自带的打砖块游戏，包含碰撞、三条生命、计分与暂停功能。完整游戏写在单个 JavaScript 文件 examples/breakout.cjs 中，方便运行与阅读。

运行准备 ​

在 monorepo 根目录执行一次 node tools/bootstrap.cjs，再 cd packages/sfml.js。下方命令均从该包目录运行，修改源码后在包内执行 npm run build。图形示例需要显示环境和 OpenGL，独立项目按各自说明安装。

sh
node examples/breakout.cjs
node examples/official/shader/Shader.cjs
node examples/network.cjs
