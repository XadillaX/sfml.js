    API reference

    Overview

    Windows, graphics, audio and networking for Node.js. Browse a module or search for an API by name.

    System

    Time, vectors and streams. The foundations shared by every module.

    Clock

    A pausable monotonic stopwatch, with no native SFML handle.

    Time

    A signed microsecond duration; native APIs receive its bigint by value.

    Vector2f

    sf::Vector2.

    All APIs52
    add

    Return a new object adding values of the same type; vectors add component-wise, and Color channels saturate at 255.

    addAssign

    Add right to left in place and return left; read-only constants cannot be modified.

    Angle

    sf::Angle's float32 value, with native ownership created on demand.

    Clock

    A pausable monotonic stopwatch, with no native SFML handle.

    degrees

    Create an angle from degrees, stored with float32 precision.

    divide

    Return a new object divided by a scalar; dividing two Time or two Angle values returns a numeric ratio.

    divideAssign

    Divide the left value by a scalar in place and return it; throw RangeError if the divisor is zero.

    equal

    Compare same-type operands by value; floating-point comparisons are exact, and vectors require the same scalar type.

    err

    A singleton Writable whose bytes are written to the actual SFML stream.

    FileInputStream

    Seekable asynchronous file input that reads directly into caller buffers.

    greater

    Test whether the left value is greater than the right; both must have the same orderable type.

    greaterEqual

    Test whether the left value is greater than or equal to the right; both must have the same orderable type.

    InputStream

    Seekable input. Each operation may complete synchronously or asynchronously.

    less

    Test whether the left value is less than the right; supports Time, Angle, VideoMode, and IpAddress.

    lessEqual

    Test whether the left value is less than or equal to the right; both must have the same orderable type.

    MemoryInputStream

    Retains the supplied bytes without copying them.

    microseconds

    Create a duration from an exact signed 64-bit microsecond count, throwing RangeError if out of range.

    milliseconds

    Create a duration from milliseconds; the input truncated toward zero must fit in a signed 32-bit integer.

    modulo

    Return the duration remainder of integer microsecond division, with the remainder taking the sign of left.

    moduloAssign

    Write the duration remainder back to left and return left.

    multiply

    Return a new object from scalar scaling, transform composition, or point transformation; Color channels are multiplied and then divided by 255.

    multiplyAssign

    Scale, compose transforms, or modulate colors in place, returning the left operand.

    negate

    Return a new negated object, converted to the original scalar type; Color is unsupported, and boolean vector values remain unchanged.

    notEqual

    Return whether same-type operands are unequal by value.

    radians

    Create an angle from radians, stored with float32 precision.

    ReadonlyValue

    Const data members recurse; methods still return independent mutable values.

    ScalarType

    Vector scalar type: i/u denotes signed/unsigned integers, f denotes floating point, and the suffix is the bit width.

    seconds

    Create a duration from seconds using float32 arithmetic, truncating to whole microseconds.

    setErrorOutput

    Process-wide SFML output: Writable redirects, null mutes, undefined resets.

    SFMLError

    Runtime failure reported by the SFML binding.

    sleep

    Asynchronous wait; the calling thread remains available to the event loop.

    StreamResult

    undefined reports an I/O failure; throws and rejected promises reject loading.

    subtract

    Return a new object subtracting values of the same type; Color channels have a minimum of 0.

    subtractAssign

    Subtract right from left in place and return left; each Color channel has a minimum of 0.

    SuspendAwareClock

    SFML's Android clock, including time spent in system suspend.

    Time

    A signed microsecond duration; native APIs receive its bigint by value.

    TimeoutPredicate

    Called once per check period; return true to keep waiting or false to stop.

    TimeoutWithPredicate

    Timeout configuration; the consuming operation performs waits and checks.

    Unicode
    isGraphemeBoundary

    Test for a grapheme boundary before UTF-16 index position using SFML's Unicode rules. The start and end are boundaries; the middle of a surrogate pair is not. Isolated surrogate code units are treated as U+FFFD.

    isSentenceBoundary

    Test for a sentence boundary before UTF-16 index position using SFML's Unicode rules. The start and end are boundaries; the middle of a surrogate pair is not. Isolated surrogate code units are treated as U+FFFD.

    isWordBoundary

    Test for a word boundary before UTF-16 index position using SFML's Unicode rules. The start and end are boundaries; the middle of a surrogate pair is not. Isolated surrogate code units are treated as U+FFFD.

    Vector2

    sf::Vector2, with a native handle lazily bound to its existing storage.

    Vector2f

    sf::Vector2.

    Vector2i

    sf::Vector2.

    Vector2u

    sf::Vector2.

    Vector3

    sf::Vector3, stored as three consecutive values of its scalar type.

    Vector3f

    A vector of three float32 components.

    Vector3i

    A vector of three signed 32-bit integer components.

    Vector3u

    A vector of three unsigned 32-bit integer components.

    version

    Runtime SFML version, cached as one immutable native-backed value.

    Version

    The version of the currently loaded native SFML library.

    Window

    Windows, input and OpenGL contexts. Connect your application to the desktop.

    Window

    An OS window with an OpenGL context, usable by Texture.update().

    Event

    SFML's variant: kind identifies the subtype; payload fields stay intact.

    VideoMode

    A video mode: pixel dimensions and bits per pixel.

    Clipboard
    getString

    Return the system clipboard text, or an empty string if it contains no text.

    setString

    Replace the system clipboard text with text.

    Context

    Native-owned OpenGL context; activation remains per native thread.

    ContextAttribute

    OpenGL context attribute bit flags.

    ContextSettings

    SFML context requests; omitted members use SFML's defaults.

    Cursor

    A system cursor or a custom RGBA pixel cursor.

    CursorType

    System cursor shapes; availability depends on the platform.

    Event

    SFML's variant: kind identifies the subtype; payload fields stay intact.

    EventData

    An event-data union discriminated by the kind field.

    EventHandlers

    Optional synchronous handlers for each event kind.

    EventKind

    Names of supported window event kinds.

    EventPayloads

    Window event kinds and their payloads; all positions are client-area pixel coordinates.

    EventVisitor

    A visitor receiving data for any window event.

    Joystick
    getAxisPosition

    Return the specified axis position, from -100 to 100.

    getButtonCount

    Return the number of buttons on the specified joystick.

    getIdentification

    Return the specified joystick's name, vendor ID, and product ID.

    hasAxis

    Return whether the joystick provides the specified axis.

    Identification

    Joystick device identification information.

    isButtonPressed

    Query the pressed state of the specified joystick button; indices start at zero.

    isConnected

    Return whether the specified joystick is connected; indices start at zero.

    update

    Refresh joystick state manually; window event processing also refreshes it.

    JoystickButtonCount

    JoystickCount

    Maximum number of supported joysticks

    getDescription

    Return a human-readable name for the physical key.

    isKeyPressed

    Query a logical key's real-time pressed state, independent of the event queue.

    localize

    Convert a physical scancode to a logical key code using the current keyboard layout.

    setVirtualKeyboardVisible

    Show or hide the on-screen keyboard on supported platforms.

    Mouse
    getPosition

    Return the mouse pixel position relative to the client area if a window is provided, or to the desktop otherwise.

    isButtonPressed

    Query a mouse button's real-time pressed state.

    setPosition

    Move the mouse using client-area pixel coordinates if a window is provided, or desktop pixel coordinates otherwise.

    MouseButton

    Mouse buttons.

    MouseButtonCount

    The total number of mouse buttons

    MouseWheel

    Mouse wheel orientations.

    ReadonlyContext

    A read-only settings interface for the current OpenGL context.

    Sensor
    getValue

    Return three-axis measurements: acceleration in m/s², angular velocity in degrees/second, magnetic field in µT, and orientation in degrees.

    isAvailable

    Return whether the device provides the specified sensor.

    setEnabled

    Enable or disable sensor data acquisition.

    SensorCount

    The total number of sensor types

    SensorType

    Sensor types.

    State

    Initial window display state.

    Style

    Window style bit flags that can be combined with bitwise OR.

    Touch
    getPosition

    Return the touch's pixel position relative to the client area of relativeTo, or to the desktop if omitted.

    isDown

    Return whether the specified touch is still down.

    VideoMode

    A video mode: pixel dimensions and bits per pixel.

    Vulkan
    getFunction

    Query a Vulkan function address, returning undefined if not found. The address uses bigint to preserve precision; calling it requires a native binding with the matching function signature.

    getGraphicsRequiredInstanceExtensions

    Return a copy of the extension names required to create a graphics instance; the contents depend on SFML's platform backend.

    isAvailable

    Query whether the SFML backend supports Vulkan; false checks only compute capabilities.

    An OS window with an OpenGL context, usable by Texture.update().

    WindowHandle

    Platform window handles and Vulkan pointers are represented losslessly.

    WindowOptions

    Window creation options.

    A window supporting both Window operations and RenderTarget 2D drawing.

    GPU texture with background image decoding and ordered pixel uploads.

    Sprite

    CoordinateType
