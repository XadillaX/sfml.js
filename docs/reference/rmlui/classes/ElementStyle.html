    ElementStyle

    Checked element-owned Rml::ElementStyle with native cascade and dirty state.

    Remarks

    Class and pseudo-class setters follow ElementStyle directly. Call updateDefinition explicitly after changing them. Queries return owned snapshots. High-frequency numeric operations use ElementCommandBuffer's style opcodes and shared planes; normal layout computation stays native. Element destruction and runtime shutdown invalidate every style operation.

    • computeValues(

          documentValues: null | ComputedValuesView,
          valuesAreDefaultInitialized: boolean,
          dpRatio: number,
          viewportDimensions: VariantVector2,
      ): Set<PropertyId>

      Compute into owned native values and consume the element's real dirty sets.

      Parameters

      values
      ComputedValues

      Writable values associated with this element.

      parentValues
      null | ComputedValuesView

      Already computed parent values, or null.

      documentValues
      null | ComputedValuesView

      Already computed document values, or null.

      valuesAreDefaultInitialized
      boolean

      Output still has native defaults.

      dpRatio
      number

      Positive finite density ratio.

      viewportDimensions
      VariantVector2

      Finite native viewport dimensions.

      Returns

      Set<PropertyId>

      Consumed dirty IDs; inherited dependencies propagate to children.

      Remarks

      Execute parents before children. This operation writes owned output only; it does not invoke Element::OnPropertyChange or update its layout. Before subsequent Context.update, redirty every returned ID on this style so Element::UpdateProperties can apply the pending values to live layout.
