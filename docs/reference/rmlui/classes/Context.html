    Context

    RmlUi context bound to one sfml.js render window.

    Remarks

    Obtain registered instances through createContext, or independently owned instances through Factory.instanceContext. The native context owns attached documents. Stop using wrappers after remove or shutdown.

    processEvent

    • processEvent(event: Event<(keyof EventPayloads)> | EventData): boolean

      Forward an sfml.js window event to the RmlUi context.

      Parameters

      event
      Event<(keyof EventPayloads)> | EventData

      sfml.js event object or event data.

      Returns

      boolean

      Propagation or interaction result; true for ignored events.

      Remarks

      Key, text and wheel events return propagation; mouse/touch input returns whether no element is interacting. Coordinates use physical pixels. Key modifiers come from the event snapshot; pointer modifiers use live keyboard state. Touch events forward a one-entry TouchList. SFML system keys map to LMETA/RMETA on macOS and LWIN/RWIN elsewhere. TextEntered normalizes CR to LF and skips other control characters. Resize events update dimensions and density automatically.
