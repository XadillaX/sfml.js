    API reference/Runtime and contextsClass

    Style.RareValues

    Owned storage for less common layout, transform and effect properties.

    Remarks

    Uses upstream defaults independently of DOM and runtime. Numeric views retain this struct only; colour getters return copies. Non-null font handles require the active runtime generation.
