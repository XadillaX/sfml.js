    addEventListener

    • addEventListener(
          type: string | number,
          listener: RmlEventListener | EventListener,
          capture?: boolean,
      ): void

      Attach an event listener.

      Parameters

      type
      string | number

      Event name or registered native EventId.

      listener
      RmlEventListener | EventListener

      Synchronous callback, shareable between registrations.

      capture
      boolean = false

      Listen in capture phase; defaults to false.

      Returns

      void

      Remarks

      Identical element/type/callback/capture registrations are idempotent. Removing the registration or destroying the element releases its callback. Listeners may remove themselves or other listeners during dispatch. Exceptions propagate from the native entry that dispatched the event. Classes, styles, target-local ordinary attributes, titles and unrelated subtrees may change synchronously. Removing active event targets or native call receivers is rejected, as are teardown and recursive update/input. Attribute set/removal also rejects ancestors of active targets. Setting or removing an active input's type is rejected to protect its widget. Schedule those operations after dispatch, for example with queueMicrotask.
