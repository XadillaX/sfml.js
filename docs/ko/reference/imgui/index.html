    sfml.js-imgui · 개요

    창 초기화, 이벤트 전달과 프레임 렌더링. 위젯, 네이티브 핸들, 콜백과 공유 상태. 글꼴 아틀라스, 글리프 범위와 스타일 색상.

    SFML

    창 초기화, 이벤트 전달과 프레임 렌더링.

    Init

    창에 대해 ImGui와 imgui-sfml 백엔드를 초기화합니다.

    Update

    ImGui 프레임 상태를 갱신하고 새 프레임을 시작합니다.

    Render

    sfml.js에 기록된 그리기를 반영하고 창에 ImGui를 그립니다.
