    sfml.js-rmlui · 개요

    초기화, 글꼴, 이벤트 전달과 프레임 렌더링. RML 로드, 요소 속성과 네이티브 객체 수명. 복사된 이벤트 데이터와 JavaScript 리스너 시그니처.

    런타임과 컨텍스트

    초기화, 글꼴, 이벤트 전달과 프레임 렌더링.

    initialise

    SFML 기반 시스템 및 렌더 인터페이스로 RmlUi를 초기화합니다.

    createContext

    이름이 있는 RmlUi 컨텍스트를 생성합니다.

    Context

    하나의 sfml.js 렌더 창에 바인딩된 RmlUi 컨텍스트입니다.
