    API 레퍼런스/런타임과 컨텍스트네임스페이스

    Style

    네이티브 계산 스타일의 형식, 값 및 해석 함수입니다.

    열거형

    AlignContent

    계산된 플렉스 줄 정렬입니다.

    AlignItems

    계산된 플렉스 항목 기본 정렬입니다.

    AlignSelf

    계산된 개별 플렉스 항목 정렬입니다.

    BoxSizing

    계산된 크기 계산 기준 상자입니다.

    Clear

    계산된 플로트 회피입니다.

    ClipType

    계산된 조상 클리핑 제어입니다.

    Direction

    계산된 텍스트 읽기 방향입니다.

    Display

    계산된 레이아웃 상자 생성 방식입니다.

    Drag

    계산된 드래그 동작입니다.

    FlexDirection

    계산된 플렉스 주축 방향입니다.

    FlexWrap

    계산된 플렉스 줄바꿈입니다.

    Float

    계산된 플로트 배치입니다.

    Focus

    계산된 포커스 허용 여부입니다.

    FontKerning

    계산된 커닝입니다.

    FontStyle

    계산된 글꼴 기울기입니다.

    FontWeight

    계산된 글꼴 굵기입니다.

    JustifyContent

    계산된 플렉스 주축 정렬입니다.

    LengthPercentageAutoType

    픽셀 길이, 백분율 또는 자동 크기입니다.

    LengthPercentageType

    픽셀 길이 또는 기준 크기에 대한 백분율입니다.

    LineHeightInheritType

    계산된 줄 높이（px）와 상속할 숫자 또는 길이입니다.

    Nav

    계산된 방향키 탐색입니다.

    NumberAutoType

    쌓임 순서에 사용하는 숫자 또는 자동 키워드입니다.

    OriginX

    계산된 수평 변환 원점입니다.

    OriginY

    계산된 수직 변환 원점입니다.

    Overflow

    계산된 넘침 처리입니다.

    OverscrollBehavior

    계산된 스크롤 연쇄입니다.

    PointerEvents

    계산된 포인터 적중 검사입니다.

    Position

    계산된 배치 방식입니다.

    TabIndex

    계산된 키보드 순차 포커스입니다.

    TextAlign

    계산된 텍스트 수평 정렬입니다.

    TextDecoration

    계산된 텍스트 장식선입니다.

    TextOverflow

    계산된 텍스트 넘침 표시입니다.

    TextTransform

    계산된 텍스트 대소문자 변환입니다.

    VerticalAlignType

    인라인 수직 정렬 키워드 또는 픽셀 오프셋입니다.

    Visibility

    계산된 표시 상태입니다.

    WhiteSpace

    계산된 공백 및 줄바꿈 처리입니다.

    WordBreak

    계산된 단어 줄바꿈입니다.

    클래스

    Clip

    부호 있는 바이트 인코딩을 유지하는 Rml::Style::Clip입니다.

    CommonValues

    일반 레이아웃 및 테두리 속성의 소유 저장소입니다.

    InheritedValues

    상속되는 텍스트·색상·입력 속성의 소유 저장소입니다.

    LengthPercentage

    픽셀 길이 또는 기준 크기에 대한 백분율입니다.

    LengthPercentageAuto

    픽셀 길이, 백분율 또는 자동 크기입니다.

    LineHeight

    계산된 줄 높이（px）와 상속할 숫자 또는 길이입니다.

    NumberAuto

    쌓임 순서에 사용하는 숫자 또는 자동 키워드입니다.

    RareValues

    덜 자주 사용하는 레이아웃·변환·효과 속성의 소유 저장소입니다.

    VerticalAlign

    인라인 수직 정렬 키워드 또는 픽셀 오프셋입니다.

    함수

    resolveValue

    두 계산 길이 형식에 대한 Rml::ResolveValue입니다.

    resolveValueOr

    두 계산 길이 형식에 대한 Rml::ResolveValueOr입니다.

    참조

    Bottom → LengthPercentageAuto

    Rml::Style::Bottom이며 길이, 백분율 또는 자동 값입니다.

    FlexBasis → LengthPercentageAuto

    Rml::Style::FlexBasis이며 길이, 백분율 또는 자동 값입니다.

    Height → LengthPercentageAuto

    Rml::Style::Height이며 길이, 백분율 또는 자동 값입니다.

    Left → LengthPercentageAuto

    Rml::Style::Left이며 길이, 백분율 또는 자동 값입니다.

    Margin → LengthPercentageAuto

    Rml::Style::Margin이며 길이, 백분율 또는 자동 값입니다.

    MaxHeight → LengthPercentage

    Rml::Style::MaxHeight이며 길이 또는 백분율입니다.

    MaxWidth → LengthPercentage

    Rml::Style::MaxWidth이며 길이 또는 백분율입니다.

    MinHeight → LengthPercentage

    Rml::Style::MinHeight이며 길이 또는 백분율입니다.

    MinWidth → LengthPercentage

    Rml::Style::MinWidth이며 길이 또는 백분율입니다.

    Padding → LengthPercentage

    Rml::Style::Padding이며 길이 또는 백분율입니다.

    PerspectiveOrigin → LengthPercentage

    Rml::Style::PerspectiveOrigin이며 길이 또는 백분율입니다.

    Right → LengthPercentageAuto

    Rml::Style::Right이며 길이, 백분율 또는 자동 값입니다.

    Top → LengthPercentageAuto

    Rml::Style::Top이며 길이, 백분율 또는 자동 값입니다.

    TransformOrigin → LengthPercentage

    Rml::Style::TransformOrigin이며 길이 또는 백분율입니다.

    Width → LengthPercentageAuto

    Rml::Style::Width이며 길이, 백분율 또는 자동 값입니다.

    ZIndex → NumberAuto

    Rml::Style::ZIndex이며 숫자 또는 자동 값입니다.
