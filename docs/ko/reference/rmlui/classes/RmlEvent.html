    RmlEvent

    RmlUi 이벤트 스냅샷이며 네이티브 전파 제어는 현재 콜백 동안만 유효합니다.

    참고

    각 리스너는 투영 좌표를 포함한 별도 스냅샷을 받습니다. 저장된 필드는 읽을 수 있지만 콜백 종료 후 전파 상태와 중단 메서드는 예외를 던집니다. id는 이벤트 종류를 식별합니다.

    getParameter

    • getParameter<const T extends VariantConversionDefault>(
          name: string,
          defaultValue: T,
      ): VariantResult<T>

      Rml::Event::GetParameter 변환이며 네이티브 이벤트가 유효할 때 사용합니다.

      타입 매개변수

      • const T extends VariantConversionDefault

        기본값으로 선택하는 네이티브 변환 형식입니다.

      매개변수

      name
      string

      네이티브 매개변수 이름입니다.

      defaultValue
      T

      T를 선택하는 null이 아닌 소유 Variant입니다.

      반환값

      VariantResult<T>

      네이티브 변환 결과이며 매개변수가 없으면 기본값입니다.

      참고

      JS 스냅샷과 독립된 투영 매개변수를 읽습니다. number는 double, BigInt는 int64이며 INT64_MAX 초과 시 uint64를 선택합니다. 비숫자 문자열의 숫자 변환 결과는 0입니다. 정수 범위 초과는 예외이며 scriptinterface 예제는 보호된 Element, Context, Event 포인터를 읽고 만료하면 null을 반환합니다. 벡터와 색상은 복사하며 보관에는 parameters를 씁니다.

      소스와 상속
      • 정의 위치: src/events/event.ts:502
