    ElementStyle

    네이티브 캐스케이드와 변경 상태를 유지하는 요소 소유 Rml::ElementStyle입니다.

    참고

    클래스와 의사 클래스 변경 후 updateDefinition을 명시적으로 호출합니다. 조회는 소유 사본이며 고빈도 수치는 공유 명령을 사용하고 배치 계산은 네이티브에서 실행합니다. 요소 파괴나 런타임 종료 후에는 무효입니다.

    소스와 상속

    computeValues

    • computeValues(
          values: ComputedValues,
          parentValues: null | ComputedValuesView,
          documentValues: null | ComputedValuesView,
          valuesAreDefaultInitialized: boolean,
          dpRatio: number,
          viewportDimensions: VariantVector2,
      ): Set<PropertyId>

      소유 값으로 계산하며 요소의 실제 변경 집합을 소비합니다.

      매개변수

      values
      ComputedValues

      이 요소에 연결된 쓰기 가능한 값입니다.

      parentValues
      null | ComputedValuesView

      계산된 부모 요소 값 또는 null입니다.

      documentValues
      null | ComputedValuesView

      계산된 문서 값 또는 null입니다.

      valuesAreDefaultInitialized
      boolean

      출력이 네이티브 기본 값인지 여부입니다.

      dpRatio
      number

      유한한 양수 밀도 비율입니다.

      viewportDimensions
      VariantVector2

      유한한 네이티브 뷰포트 크기입니다.

      반환값

      Set<PropertyId>

      소비된 변경 ID를 반환하고 상속 의존성을 자식에게 전달합니다.

      참고

      부모부터 자식 순서로 실행하며 배치를 갱신하지 않습니다. 다음 Context.update 전에 반환된 모든 ID를 dirtyProperty로 표시하여 실제 배치에 적용하세요.
