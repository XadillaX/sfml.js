    StyleSheet

    Rml::StyleSheet: 검증된 컴파일 뷰 또는 소유하는 결합 결과입니다.

    참고

    컨테이너 뷰를 combineStyleSheet로 결합하면 수정 가능한 시트를 얻습니다. mergeStyleSheet와 buildNodeIndex는 소유 결합 결과에서만 허용됩니다. shutdown은 두 형식을 모두 무효화하며 스프라이트 정보는 사본입니다.

    소스와 상속

      지정한 렌더 관리자로 Rml::StyleSheet 장식기를 생성합니다.

      매개변수

      장식기 리소스를 소유하는 관리자입니다.

      source

      텍스처 상대 경로에 사용할 선택적 선언 위치입니다.

      반환값

      Decorator<object>[]

      공유 인스턴스의 독립 배열이며 네이티브 생성 실패 시 빈 배열입니다.

      참고

      선언 문자열이 비어 있지 않으면 문자열, 원본 경로, 관리자로 캐시합니다. 빈 문자열이면 호출할 때마다 새 인스턴스를 생성합니다.
