    API 레퍼런스/런타임과 컨텍스트클래스

    Context

    하나의 sfml.js 렌더 창에 바인딩된 RmlUi 컨텍스트입니다.

    참고

    등록 인스턴스는 createContext, 독립 소유 인스턴스는 Factory.instanceContext로 얻습니다. 컨텍스트는 연결한 문서를 소유하며, Context.remove 또는 shutdown 후에는 관련 래퍼를 사용할 수 없습니다.

    processEvent

    • processEvent(event: Event<(keyof EventPayloads)> | EventData): boolean

      sfml.js 창 이벤트를 RmlUi에 전달합니다.

      매개변수

      event
      Event<(keyof EventPayloads)> | EventData

      sfml.js 이벤트 객체 또는 이벤트 데이터입니다.

      반환값

      boolean

      상위 라이브러리의 전파 또는 상호작용 결과입니다. 무시한 이벤트는 true입니다.

      참고

      키·텍스트·휠은 전파 상태, 마우스·터치는 요소와 상호작용하지 않는지 반환합니다. 좌표는 물리 픽셀입니다. 키 보조 키는 이벤트 스냅샷, 포인터 보조 키는 현재 상태입니다. 터치는 항목 하나의 TouchList로 전달합니다. 시스템 키는 macOS에서 LMETA/RMETA, 다른 플랫폼에서 LWIN/RWIN입니다. TextEntered는 CR을 LF로 바꾸고 다른 제어 문자를 건너뜁니다. 크기 변경 시 크기와 밀도를 갱신합니다.
