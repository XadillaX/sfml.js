      요소, 유형, 콜백, capture가 같은 등록은 중복되지 않습니다. 제거나 요소 파괴 시 자동 해제되며 실행 중 자신이나 다른 리스너를 제거할 수 있습니다. 예외는 이벤트를 발생시킨 호출로 전파됩니다. 클래스, 스타일, 속성, 제목, 무관한 하위 트리는 동기 변경할 수 있습니다. 활성 이벤트 대상이나 네이티브 호출 대상 파괴, 종료, 재귀 갱신 및 입력은 거부됩니다. 속성 설정과 제거는 활성 대상의 상위 요소에서도 거부됩니다. 활성 입력 요소의 type 설정과 제거도 실행 중인 네이티브 위젯을 보호하기 위해 거부됩니다. 이런 작업은 queueMicrotask 등으로 이벤트 처리 이후에 예약하세요.
