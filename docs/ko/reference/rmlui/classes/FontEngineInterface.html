    FontEngineInterface

    공유 값과 선택적 호스트 가상 함수를 제공하는 네이티브 인터페이스입니다.

    참고

    선택된 엔진만 작업할 수 있습니다. Core가 수명 주기를 관리하며 생성은 provider를 시작하지 않습니다. 기본 글리프와 아틀라스는 C++에서 처리하며 사용자 지정 가상 함수는 동기 호스트 콜백으로 실행합니다.
