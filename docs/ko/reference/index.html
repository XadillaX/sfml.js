    API 레퍼런스

    개요

    Node.js를 위한 윈도우, 그래픽, 오디오, 네트워크 API입니다. 모듈별로 살펴보거나 API 이름으로 검색하세요.

    System

    시간, 벡터, 스트림. 모든 모듈의 기반 기능.

    Clock

    일시 정지 가능한 단조 스톱워치. 네이티브 SFML 핸들을 갖지 않는다.

    Time

    부호 있는 마이크로초 시간 길이. 네이티브 API는 bigint를 값으로 전달받는다.

    Vector2f

    sf::Vector2. 부동소수점형 2차원 벡터.

    모든 API52
    add

    같은 타입의 값을 더한 새 객체를 반환한다. 벡터는 성분별로 더하며 Color 채널은 255에서 포화된다.

    addAssign

    left에 right를 제자리에서 더하고 left를 반환한다. 읽기 전용 상수는 수정 불가.

    Angle

    sf::Angle의 float32 값. 네이티브 소유권은 필요할 때 생성된다.

    Clock

    일시 정지 가능한 단조 스톱워치. 네이티브 SFML 핸들을 갖지 않는다.

    degrees

    도 단위 값으로 각도를 생성하고 float32 정밀도로 저장한다.

    divide

    스칼라로 나눈 새 객체를 반환한다. 두 Time 또는 두 Angle을 나누면 수치 비율을 반환한다.

    divideAssign

    왼쪽 값을 스칼라로 제자리에서 나누고 반환한다. 제수가 0이면 RangeError를 던진다.

    equal

    같은 타입의 피연산자를 값으로 비교한다. 부동소수점은 정확히 비교하며 벡터는 같은 스칼라 타입이어야 한다.

    err

    바이트가 실제 SFML 스트림에 기록되는 싱글턴 Writable.

    FileInputStream

    호출자의 버퍼로 직접 읽는 탐색 가능한 비동기 파일 입력.

    greater

    왼쪽 값이 오른쪽 값보다 큰지 판별한다. 둘 다 같은 정렬 가능한 타입이어야 한다.

    greaterEqual

    왼쪽 값이 오른쪽 값 이상인지 판별한다. 둘 다 같은 정렬 가능한 타입이어야 한다.

    InputStream

    탐색 가능한 입력. 각 작업은 동기 또는 비동기로 완료될 수 있다.

    less

    왼쪽 값이 오른쪽 값보다 작은지 판별한다. Time, Angle, VideoMode, IpAddress를 지원한다.

    lessEqual

    왼쪽 값이 오른쪽 값 이하인지 판별한다. 둘 다 같은 정렬 가능한 타입이어야 한다.

    MemoryInputStream

    제공된 바이트를 복사하지 않고 유지한다.

    microseconds

    정확한 부호 있는 64비트 마이크로초 수로 시간 길이를 생성한다. 범위를 벗어나면 RangeError를 던진다.

    milliseconds

    밀리초 수로 시간 길이를 생성한다. 0 방향으로 절삭한 입력은 부호 있는 32비트 정수 범위 내여야 한다.

    modulo

    정수 마이크로초 나눗셈의 나머지를 시간 길이로 반환한다. 부호는 left를 따른다.

    moduloAssign

    시간 길이의 나머지를 left에 다시 쓰고 left를 반환한다.

    multiply

    스칼라 배율 적용, 변환 합성 또는 점 변환으로 새 객체를 반환한다. Color는 채널별로 곱한 뒤 255로 나눈다.

    multiplyAssign

    배율 적용, 변환 합성 또는 색상 변조를 제자리에서 수행하고 왼쪽 피연산자를 반환한다.

    negate

    부호를 반전하고 원래 스칼라 타입으로 변환한 새 객체를 반환한다. Color는 지원하지 않으며 불리언 벡터 값은 그대로 유지된다.

    notEqual

    같은 타입의 피연산자가 값으로 같지 않은지 반환한다.

    radians

    라디안 값으로 각도를 생성하고 float32 정밀도로 저장한다.

    ReadonlyValue

    데이터 멤버는 재귀적으로 읽기 전용이 됩니다. 메서드는 여전히 독립적인 변경 가능 값을 반환할 수 있습니다.

    ScalarType

    벡터 스칼라 유형입니다. i/u는 부호 있는/없는 정수, f는 부동 소수점을 나타내며 접미사는 비트 수입니다.

    seconds

    float32 연산을 사용하고 정수 마이크로초로 절삭하여 초 수로 시간 길이를 생성한다.

    setErrorOutput

    프로세스 전체 SFML 출력. Writable은 리디렉션, null은 출력 차단, undefined는 초기화한다.

    SFMLError

    SFML 바인딩이 보고하는 런타임 오류.

    sleep

    비동기 대기. 호출 스레드는 계속 이벤트 루프에서 사용할 수 있다.

    StreamResult

    undefined는 I/O 실패를 나타낸다. 예외를 던지거나 거부된 Promise를 반환하면 로드 작업의 Promise도 거부된다.

    subtract

    같은 타입의 값을 뺀 새 객체를 반환한다. Color 채널의 최솟값은 0이다.

    subtractAssign

    left에서 right를 제자리에서 빼고 left를 반환한다. 각 Color 채널의 최솟값은 0.

    SuspendAwareClock

    시스템 일시 중단 시간도 포함하는 SFML의 Android 시계.

    Time

    부호 있는 마이크로초 시간 길이. 네이티브 API는 bigint를 값으로 전달받는다.

    TimeoutPredicate

    확인 주기마다 한 번 호출된다. true를 반환하면 대기 지속, false면 종료한다.

    TimeoutWithPredicate

    시간 제한 설정. 이 설정을 사용하는 작업이 대기와 확인을 수행한다.

    Unicode
    isGraphemeBoundary

    SFML의 Unicode 규칙으로 UTF-16 인덱스 position 직전이 자소 경계인지 판별한다. 시작과 끝은 경계이며 서로게이트 쌍 사이는 경계가 아니다. 고립된 서로게이트 코드 단위는 U+FFFD로 처리한다.

    isSentenceBoundary

    SFML의 Unicode 규칙으로 UTF-16 인덱스 position 직전이 문장 경계인지 판별한다. 시작과 끝은 경계이며 서로게이트 쌍 사이는 경계가 아니다. 고립된 서로게이트 코드 단위는 U+FFFD로 처리한다.

    isWordBoundary

    SFML의 Unicode 규칙으로 UTF-16 인덱스 position 직전이 단어 경계인지 판별한다. 시작과 끝은 경계이며 서로게이트 쌍 사이는 경계가 아니다. 고립된 서로게이트 코드 단위는 U+FFFD로 처리한다.

    Vector2

    sf::Vector2. 네이티브 핸들은 기존 저장소에 지연 바인딩된다.

    Vector2f

    sf::Vector2. 부동소수점형 2차원 벡터.

    Vector2i

    sf::Vector2. 정수형 2차원 벡터.

    Vector2u

    sf::Vector2. 부호 없는 정수형 2차원 벡터.

    Vector3

    sf::Vector3. 해당 스칼라 타입의 연속된 세 값으로 저장된다.

    Vector3f

    세 개의 float32 성분으로 구성된 벡터.

    Vector3i

    세 개의 부호 있는 32비트 정수 성분으로 구성된 벡터.

    Vector3u

    세 개의 부호 없는 32비트 정수 성분으로 구성된 벡터.

    version

    런타임 SFML 버전. 네이티브 저장소에 기반한 단일 불변 값으로 캐시된다.

    Version

    현재 로드된 네이티브 SFML 라이브러리 버전.

    Window

    윈도우, 입력, OpenGL 컨텍스트. 데스크톱 환경과의 연결.

    Window

    OpenGL 컨텍스트가 있는 OS 윈도우. Texture.update()에서 사용할 수 있다.

    Event

    SFML의 변형 타입. kind로 하위 타입을 식별하며 페이로드 필드는 그대로 유지된다.

    VideoMode

    비디오 모드. 픽셀 크기와 픽셀당 비트 수.

    모든 API64
    Clipboard
    getString

    시스템 클립보드 텍스트를 반환한다. 텍스트가 없으면 빈 문자열을 반환한다.

    setString

    시스템 클립보드 텍스트를 text로 교체한다.

    Context

    네이티브 측이 소유한 OpenGL 컨텍스트. 활성화는 네이티브 스레드별로 유지된다.

    ContextAttribute

    OpenGL 컨텍스트 속성 비트 플래그.

    ContextSettings

    SFML 컨텍스트 요청. 생략한 멤버는 SFML 기본값을 사용한다.

    Cursor

    시스템 커서 또는 사용자 정의 RGBA 픽셀 커서.

    CursorType

    시스템 커서 모양. 지원 여부는 플랫폼에 따라 다릅니다.

    Event

    SFML의 변형 타입. kind로 하위 타입을 식별하며 페이로드 필드는 그대로 유지된다.

    EventData

    kind 필드로 판별하는 이벤트 데이터 유니온 타입.

    EventHandlers

    이벤트 종류별로 선택적으로 제공하는 동기 핸들러.

    EventKind

    지원하는 윈도우 이벤트 종류의 이름.

    EventPayloads

    윈도우 이벤트 종류와 부속 데이터. 위치는 모두 클라이언트 영역 픽셀 좌표이다.

    EventVisitor

    모든 윈도우 이벤트 데이터를 받는 방문 함수.

    Joystick
    getAxisPosition

    지정한 축의 위치를 -100～100 범위로 반환한다.

    getButtonCount

    지정한 조이스틱의 버튼 수를 반환한다.

    getIdentification

    지정한 조이스틱의 이름, 제조사 식별자, 제품 식별자를 반환한다.

    hasAxis

    조이스틱이 지정한 축을 제공하는지 반환한다.

    Identification

    조이스틱 장치 식별 정보.

    isButtonPressed

    지정한 조이스틱 버튼의 눌림 상태를 조회한다. 번호는 0부터 시작한다.

    isConnected

    지정한 조이스틱이 연결되어 있는지 반환한다. 번호는 0부터 시작한다.

    update

    조이스틱 상태를 수동으로 갱신한다. 윈도우 이벤트 처리에서도 갱신된다.

    JoystickAxis

    조이스틱 축.

    JoystickAxisCount

    지원되는 축의 최대 수

    JoystickButtonCount

    지원되는 버튼의 최대 수

    JoystickCount

    지원되는 조이스틱의 최대 수

    Keyboard
    delocalize

    현재 키보드 레이아웃에 따라 논리 키 코드를 물리 스캔 코드로 변환한다.

    getDescription

    물리 키의 사용자가 읽을 수 있는 이름을 반환한다.

    isKeyPressed

    이벤트 큐와 무관하게 논리 키의 실시간 눌림 상태를 조회한다.

    localize

    현재 키보드 레이아웃에 따라 물리 스캔 코드를 논리 키 코드로 변환한다.

    setVirtualKeyboardVisible

    지원하는 플랫폼에서 화면 키보드를 표시하거나 숨긴다.

    KeyboardKey

    시스템 키보드 배열에 따라 달라지는 논리 키.

    KeyboardKeyCount

    Key::Unknown을 제외한 키보드 키의 총수

    KeyboardScancode

    키보드 배열과 무관한 물리 키.

    KeyboardScancodeCount

    Scan::Unknown을 제외한 스캔 코드의 총수

    Mouse
    getPosition

    마우스 픽셀 위치를 반환한다. 윈도우를 제공하면 클라이언트 영역 기준이며 그렇지 않으면 데스크톱 기준이다.

    isButtonPressed

    마우스 버튼의 실시간 눌림 상태를 조회한다.

    setPosition

    마우스를 이동한다. 윈도우를 제공하면 클라이언트 영역 픽셀 좌표를 사용하며 그렇지 않으면 데스크톱 픽셀 좌표를 사용한다.

    MouseButton

    마우스 버튼.

    MouseButtonCount

    마우스 버튼의 총수

    MouseWheel

    마우스 휠 방향.

    ReadonlyContext

    현재 OpenGL 컨텍스트의 읽기 전용 설정 인터페이스.

    Sensor
    getValue

    3축 측정값을 반환한다. 가속도는 m/s², 각속도는 도/초, 자기장은 µT, 방향은 도 단위이다.

    isAvailable

    장치가 지정한 센서를 제공하는지 반환한다.

    setEnabled

    센서 데이터 수집을 활성화하거나 비활성화한다.

    SensorCount

    센서 유형의 총수

    SensorType

    센서 유형.

    State

    창의 초기 표시 상태.

    Style

    비트 OR 연산으로 조합할 수 있는 창 스타일 플래그.

    Touch
    getPosition

    relativeTo의 클라이언트 영역 기준 터치 픽셀 위치를 반환한다. 생략하면 데스크톱 기준이다.

    isDown

    지정한 터치가 아직 눌려 있는지 반환한다.

    VideoMode

    비디오 모드. 픽셀 크기와 픽셀당 비트 수.

    Vulkan
    getFunction

    Vulkan 함수 주소를 조회하고 찾지 못하면 undefined를 반환한다. 주소는 bigint로 정밀도를 유지한다. 호출하려면 함수 시그니처와 일치하는 네이티브 바인딩이 필요하다.

    getGraphicsRequiredInstanceExtensions

    그래픽 인스턴스 생성에 필요한 확장 이름의 복사본을 반환한다. 내용은 SFML 플랫폼 백엔드에 따라 달라진다.

    isAvailable

    SFML 백엔드가 Vulkan을 지원하는지 조회한다. false이면 연산 기능만 확인한다.

    Window

    OpenGL 컨텍스트가 있는 OS 윈도우. Texture.update()에서 사용할 수 있다.

    WindowHandle

    플랫폼 윈도우 핸들과 Vulkan 포인터를 손실 없이 표현한다.

    WindowOptions

    윈도우 생성 옵션.

    Graphics

    텍스처, 도형, 텍스트, 렌더링. 2D 장면 구성.

    RenderWindow

    Window 창 작업과 RenderTarget 2차원 그리기를 모두 지원하는 창입니다.

    Texture

    백그라운드 이미지 디코딩과 순서가 보장되는 픽셀 업로드를 지원하는 GPU 텍스처입니다.

    Sprite

    공통 Transformable API를 갖춘 sf::Sprite입니다.

    서비스 검색 레코드(예: _service._tcp.domain)를 조회하며, 실패 시 빈 배열을 반환합니다.

    queryTxt

    TXT 레코드를 조회합니다. 각 레코드는 여러 텍스트 조각을 포함하며, 실패 시 빈 배열을 반환합니다.

    resolve

    IPv4/IPv6 주소를 비동기로 확인하며 실패 시 undefined를 반환합니다. servers가 비어 있으면 시스템 리졸버를 사용하고 timeout은 적용하지 않습니다. DNS 서버를 지정하면 기본 제한 시간은 1초입니다.

    SrvRecord

    서비스 검색 레코드.

    FileType

    원격 파일 시스템 항목 타입.

    Ftp

    basic-ftp 기반 FTP 클라이언트. 작업은 큐를 통해 호출 순서대로 실행됩니다.

    FtpDirectoryResponse

    작업 디렉터리 경로를 포함하는 FTP 응답.

    FtpListingResponse

    디렉터리 항목 이름을 포함하는 FTP 응답.

    FtpResponse

    FTP 상태 코드와 서버 메시지.

    FtpStatus

    FTP 서버 응답 코드 및 클라이언트 오류 코드.

    Http

    요청당 하나의 연결을 사용하는 HTTP/HTTPS 클라이언트. 리디렉션을 자동으로 따르지 않습니다.

    HttpMethod

    HTTP 요청 메서드.

    HttpRequest

    변경 가능한 HTTP/1 요청. 기본값은 GET /, HTTP/1.0 및 빈 본문입니다.

    HttpResponse

    HTTP 응답 상태, 헤더 필드 및 본문.

    HttpStatus

    HTTP 응답 상태 및 클라이언트 오류. 값은 SFML 정의를 유지합니다.

    IpAddress

    IPv4와 IPv6를 지원하는 불변 IP 주소 값.

    IpAddressType

    IP 주소 계열.

    Packet

    정수는 네트워크 순서를, SFML 부동소수점 수는 호스트 순서를 사용합니다.

    PacketType

    Packet.write/read가 허용하는 인코딩 타입 이름.

    PacketValues

    Packet 인코딩 타입과 해당 JS 값. 멀티바이트 정수는 네트워크 순서입니다.

    ReadinessType

    비트 플래그로 조합할 수 있는 소켓 준비 조건.

    ReadyCallback

    이번 wait에서 얻은 준비 상태 비트 플래그를 받습니다.

    Sftp

    ssh2 기반 비동기 SFTP 클라이언트. 파일 작업은 호출 순서대로 실행됩니다.

    SftpAttributes

    원격 항목 속성. 서버가 제공하지 않은 필드는 undefined입니다.

    SftpAttributesResult

    파일 시스템 항목 하나의 속성을 포함하는 결과.

    SftpDownloadCallback

    다운로드 청크를 처리하며 false를 반환하면 조기 종료합니다. 빈 청크는 파일 끝을 나타냅니다.

    SftpHostKeyType

    SSH 서버 호스트 공개 키 유형.

    SftpListingResult

    디렉터리 항목 속성 목록을 포함하는 결과.

    SftpPathResult

    원격 경로를 포함하는 작업 결과.

    SftpResult

    SFTP 작업 상태와 메시지.

    SftpResultValue

    SFTP 작업 결과 코드.

    SftpSessionInfo

    애플리케이션이 호스트 공개 키와 알고리즘을 검증하는 데 사용하는 SSH 핸드셰이크 협상 결과.

    SftpTimeout

    진행이 없을 때의 제한 시간 설정. 데이터 수신 또는 RPC 완료 시 타이머를 재설정하며 기간이 0이면 제한 시간이 없습니다.

    SftpUploadCallback

    업로드 청크를 채우고 size를 설정합니다. false를 반환해도 현재 청크를 보낸 후 종료합니다.

    SftpUploadChunk

    업로드 콜백이 받는 채울 수 있는 데이터 청크.

    Socket

    Node 네트워크 전송의 공통 기본 클래스. 기본적으로 비동기 대기로 구현한 블로킹 동작을 사용합니다.

    SocketHandle

    Node TCP, UDP 또는 리스너 전송 객체. 운영 체제의 원시 파일 디스크립터는 허용하지 않습니다.

    SocketSelector

    소켓 집합이 준비될 때까지 비동기로 기다리고 최근 wait 결과를 보관합니다.

    SocketSendResult

    원시 TCP 바이트 송신 결과.

    SocketStatus

    소켓 작업 결과. 블로킹 모드는 Promise로 기다리며 Node 이벤트 루프를 차단하지 않습니다.

    SocketTransfer

    원시 TCP 바이트 읽기 결과.

    SocketType

    sf::Socket::Type에 해당하는 소켓 전송 프로토콜.

    TcpListener

    TCP 연결을 수신 대기하고 accept로 TcpSocket에 전달합니다.

    TcpSocket

    원시 바이트, SFML Packet 프레이밍 및 TLS 업그레이드를 지원하는 TCP 소켓.

    TlsStatus

    TLS 업그레이드의 현재 상태.

    TransferMode

    FTP 파일 전송 모드.

    UdpSocket

    데이터그램 경계를 유지하는 UDP 소켓. Packet에 TCP 길이 헤더를 붙이지 않습니다.
