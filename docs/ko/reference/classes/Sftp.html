    upload

    • upload(
          path: string,
          callback: SftpUploadCallback,
          permissions?: number,
          truncate?: boolean,
          append?: boolean,
          offset?: bigint,
          timeout?: SftpTimeout,
      ): Promise<SftpResult>

      콜백이 제공하는 청크로 파일을 업로드하며 각 청크의 쓰기 완료를 기다립니다.

      매개변수

      path
      string

      원격 파일 경로.

      callback
      SftpUploadCallback

      버퍼를 채우고 size를 설정하는 콜백.

      permissions
      number = 0o644

      새 파일 권한. 기본값은 0o644입니다.

      truncate
      boolean = true

      기존 파일을 비울지 여부. 기본값은 true입니다.

      append
      boolean = false

      추가 쓰기를 요청할지 여부. 기본값은 false입니다.

      offset
      bigint = 0n

      시작 바이트 오프셋. 기본값은 0n, 최대값은 2^53-1입니다.

      timeout
      SftpTimeout = Time.Zero

      진행이 없을 때의 제한 시간 설정. 기본적으로 제한이 없습니다.

      반환값

      Promise<SftpResult>
