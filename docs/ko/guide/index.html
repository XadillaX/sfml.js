sfml.js 문서 ​

이 문서는 현재 저장소의 SFML 3.1.0 바인딩을 설명합니다. 처음 사용한다면 '빠른 시작'부터 읽으세요. 구체적인 메서드 시그니처는 TypeDoc에서 확인할 수 있습니다.

시작하기 ​

문서다루는 문제
빠른 시작의존성 설치, 가져오기 방식 선택, 첫 번째 창 열기
핵심 개념값과 리소스의 복사 방식, 로딩 완료 시점, draw 적용 시점
API 안내다섯 모듈이 각각 제공하는 기능
예제 목록저장소에서 완전한 데모 실행하기

모듈내용

NetworkPacket, TCP/UDP, DNS, TLS, HTTP, FTP, SFTP

개발 참여 ​

개발 가이드는 빌드, 테스트, 소스 구조, 현재의 문서 게시 절차를 설명합니다.

메서드 시그니처와 내보내기 목록은 src/index.ts 및 소스 주석을 기준으로 합니다. 업스트림 개념은 SFML 3.1.0 C++ 문서 색인을 참고하세요. JavaScript에 맞게 조정한 동작은 sfml.js 가이드와 TypeDoc을 기준으로 하며, Node.js의 비동기 처리, 메모리, 네트워크 어댑테이션은 이 프로젝트의 설명을 따릅니다.
