실행 준비 ​

monorepo 루트에서 node tools/bootstrap.cjs를 실행한 뒤 cd packages/sfml.js로 이동합니다. 아래 명령은 이 패키지 디렉터리에서 실행하며 소스 변경 후에는 npm run build를 사용합니다. 그래픽 예제에는 디스플레이와 OpenGL이 필요하고 별도 프로젝트는 각 설치 안내를 따릅니다.

sh
node examples/breakout.cjs
node examples/official/shader/Shader.cjs
node examples/network.cjs
