RmlUi 예제 ​

네이티브 SFML 창에서 RmlUi 문서를 실행합니다. 카운터로 시작해 테마, 이동 가능한 창, 템플릿, 시각 테스트 페이지를 살펴보세요.

준비 사항 ​

모든 명령은 monorepo 루트에서 실행합니다. bootstrap은 의존성을 설치하고 패키지를 빌드합니다. 디스플레이와 OpenGL이 필요하며 macOS 빌드는 Xcode Command Line Tools와 CMake도 필요합니다. 빠른 시작을 참고하세요.

sh
node tools/bootstrap.cjs

RmlUi TypeScript 소스를 수정한 뒤에는 npm run build:ts --prefix packages/sfml.js-rmlui를 실행합니다. 예제는 로컬에서 빌드한 패키지를 사용합니다.

실행기는 패키지의 third_party/rmlui에 있는 RmlUi 6.3 기본 리소스를 읽습니다. 전체 항목을 보려면:

sh
node packages/sfml.js-rmlui/examples/official.cjs --list

예제 목록 ​

카운터

JavaScript 리스너, 외부 RML, 블러, 드롭 섀도, 둥근 클리핑

node packages/sfml.js-rmlui/examples/demo.cjs

조작: Increment를 클릭해 값을 올립니다. 창을 닫으면 종료합니다.

RML · RCSS

테마와 변수

테마 전환, 강조색, 호버 스타일

node packages/sfml.js-rmlui/examples/official.cjs variables

조작: 1은 어두운 테마, 2는 밝은 테마, 3은 고대비, R은 무작위 강조색, C는 강조색 초기화입니다. Escape로 종료합니다. 미션 버튼은 호버 스타일만 보여 주며 상위 프로젝트에도 클릭 동작이 없습니다.

원래 스타일시트는 고정 px 길이를 사용합니다. highDpi: false로 Retina에서도 1024 × 768 프레임버퍼를 유지하여 상위 프로젝트의 창 크기에 맞춥니다. F8로 Debugger를 전환하고 Ctrl +/-/0로 Shell 표시 밀도를 조정합니다.

좌우 키로 이동, Space로 발사, Escape로 일시 정지 메뉴, F8로 Debugger를 전환합니다. 원본 메뉴에서 다시 시작하거나 종료합니다.

먼저 패키지를 빌드하세요. 게임 모듈은 같은 빌드 디렉터리에 생성되며 로드할 때 컴파일러가 필요하지 않습니다. macOS는 검증되었으며 Linux와 Windows의 실제 실행은 미검증입니다.

점수는 앱 데이터 폴더에 저장합니다. --scores-file /absolute/path/scores.txt는 기존 상위 폴더의 파일을 지정합니다. --frames 8 --exercise로 프레임 수를 제한하여 시작합니다.

조작: F6 / F7로 페이지를 전환하고 Escape로 종료합니다.

--frames 60을 붙이면 60프레임 뒤 종료합니다. --frames N은 양의 정수를 받으므로 제한된 스모크 실행에 유용합니다. 상위 프로젝트의 검증 하네스를 포함하지 않는 미리보기입니다.

상위 VisualTests · 렌더러 지원 범위

VisualTests 113페이지 검증, 실제 IME 확인, 게임의 나머지 플랫폼 작업 및 전체 프로젝트 독립 검증은 아직 완료되지 않았습니다. 렌더러와 모듈 검증 근거는 각 가이드에 기록되어 있습니다. 스크린샷은 실행 중인 네이티브 애플리케이션입니다.
