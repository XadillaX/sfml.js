이전 버전 예제 ​

이 디렉터리는 이전 example/의 데모 진입점 16개를 유지합니다. 파일 이름은 같으며 확장자는 .cjs입니다. 14개는 현재 API에 맞게 조정되었고, 비동기 그리기 진입점 2개는 UNSUPPORTED를 출력하며 종료 코드는 2입니다.

전체 예제 · API 안내 · 개발 가이드

이 스크립트들은 이전 장면이 현재 API에서 어떻게 동작하는지 관찰하기 위한 것입니다. 새 애플리케이션은 빠른 시작부터 시작하세요.

실행 ​

프로젝트 루트 디렉터리에서 실행합니다.

sh
# 최초 빌드에는 네이티브 모듈이 포함됩니다.
npm run build

# 종합 창을 엽니다.
npm run demo:ported

# 포팅된 스크립트 중 하나를 실행합니다.
node examples/ported/texture.cjs
node examples/ported/sound_buffer.cjs

# 실행 결과를 검증하고 통과와 미지원을 구분해 보고합니다.
npm run test:ported

창 조작 ​

render_window.cjs는 원래의 VideoMode.getFullscreenModes()[3], 제목 hello, style 5를 사용합니다. 빨간 배경, 기존 장면 레이아웃, 기본 볼륨, 시작 시 Sound 한 번 재생을 유지하며, Music에는 반복만 설정하고 재생하지 않습니다. setFramerateLimit(60)과 setImmediate(frame) 스케줄링을 유지합니다.

키동작
Esc/닫기 이벤트창 닫기. Esc는 실시간 조회도 유지
Left창 위치의 x/y에 각각 1 더하기
LControl누르고 있는 동안 800×600으로 다시 생성하고 수직 동기화 켜기
LAlt컨텍스트 설정 출력
RAlt창 제목 변경
S시스템 지원 여부에 따라 가상 키보드 표시 요청

원래 마우스 로직도 유지합니다. 매 프레임 데스크톱 좌표와 창 기준 상대 좌표를 읽고, 원래 mode 범위로 제한한 뒤 Mouse.setPosition을 호출합니다. 원래 키 반복 동작도 유지합니다.

Windows 이외의 환경에서 종합 예제는 여전히 /tmp/xxx.png를 저장합니다. SoundBuffer 예제는 여전히 os.tmpdir() 아래의 .game.wav에 저장한 뒤 다시 로드하며, 자동으로 삭제하지 않습니다.

포팅 규칙 ​

조정 범위는 가져오기 경로, SFML 3 매개변수와 메서드 이름, 값 타입, 비동기 로딩입니다. 장면 매개변수, 애니메이션 공식, 그리기 순서, 입력, 파일 출력, 프레임 스케줄링은 원래 로직을 유지합니다. 이미지, 폰트, 오디오는 assets/에 있습니다.

이름에 async가 포함된 두 진입점은 동기식 그리기나 고정 sleep으로 이전 인터페이스를 흉내 내지 않습니다. display 비교 코드는 10프레임, 50 ms 하트비트, setImmediate 래핑, displayAsync, 닫은 뒤 오류 검사를 유지합니다. 종합 비동기 장면은 drawAsync/displayAsync를 차례로 await하는 동작을 유지합니다.

좌표와 크기에는 Vector2, 회전에는 Angle, 색상에는 Color를 사용합니다. 이벤트는 is/getIf로 읽고, 수치 열거형을 순회할 때는 역방향 매핑을 걸러 냅니다. 로딩 작업의 boolean을 확인하며, 원래의 누락 경로 abcdefg/abc.jpg도 유지합니다. console.log/JSON.stringify는 새 버전 객체를 직접 받아 타입 자체의 표현 방식을 따릅니다. 정수 변환과 잘못된 값 처리도 새 값 타입의 규칙을 따르며, 예제 계층에서 이전 검증을 흉내 내지 않습니다.

각 스크립트는 독립적으로 데모 로직을 포함하며, 더 이상 공유 장면이나 출력 형식 보조 함수를 사용하지 않습니다. 기존 동기식 리소스 로딩은 원래 순서대로 await하도록 바뀌었으며, 병렬 사전 로딩으로 바꾸지 않았습니다.

자동 검증 ​

test:ported는 독립적인 테스트 사전 로딩 스크립트를 사용하며, 일반적인 예제 실행에서는 이를 로드하지 않습니다. 테스트 중에는 널 오디오 장치를 선택하고, 마우스 설정을 검사하되 시스템 포인터를 움직이지 않으며, 파일 출력은 격리 디렉터리에 저장합니다. 가상 디스플레이의 전체 화면 모드가 네 개 미만이면 테스트가 데스크톱 모드로 선택지를 채웁니다.

종합 창은 8프레임을 실행한 뒤 테스트 스크립트가 닫으며, 프레임마다 레이아웃, 색상, 점 개수, 배율, 텍스트, 정점 선을 확인합니다. 테스트는 실행 가능한 진입점 14개와 미지원 진입점 2개를 별도로 집계하며, 미지원을 포팅 성공으로 계산하지 않습니다. 널 오디오 장치 테스트는 실제 스피커 출력이 정상이라는 것을 증명하지 않습니다.
