On this page

Examples ​

For examples in this repository, run npm ci from its root before the first launch and npm run build after source changes. Graphics examples need a graphical session with OpenGL window support. Separate projects have their own installation commands.

Start here ​

  • Breakout: a complete game with collisions, lives, scoring and pause/resume.

  • Shader: five official shader scenes with keyboard and mouse controls.

  • 16 games: the full ClojureScript gallery, from Tetris to Asteroids.

Browse by topic ​

  • Feature examples: 15 entry points grouped by System, Window, Graphics, Audio and Network.

  • Official examples: 24 SFML ports with controls, platform requirements and upstream credits.

  • Games and applications: Breakout, five JavaScript games, 16 ClojureScript games and play-nes.

Before running ​

sh
node examples/breakout.cjs
node examples/official/shader/Shader.cjs
node examples/network.cjs
