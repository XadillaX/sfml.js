Before running ​

At the monorepo root, run node tools/bootstrap.cjs once, then cd packages/sfml.js. Run the commands below from that package directory. Use npm run build there after source changes. Graphics examples require a display and OpenGL; separate projects follow their own setup instructions.

sh
node examples/breakout.cjs
node examples/official/shader/Shader.cjs
node examples/network.cjs
