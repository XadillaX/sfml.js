# RmlUi 6.3 性能架构验收结果

本次本地验收完成 37 个成功场景、77 组数据负载和 18 组字体负载，保留 7,600 个完整 CPU 帧样本，失败场景为 0。共享元素命令、显式批量 view、真实变更驱动的所有权维护、连续兼容几何合批及 Native 异步资源预加载均已有执行证据。这里的通过范围是本地性能架构及行为契约；RmlUi 6.3 全部 API、所有官方应用和其他平台的验收仍未完成。

[完整原始样本、计数、指纹及验证日志](architecture-performance-results.json)、[数据 CSV](architecture-performance-results.csv)、[字体 CSV](architecture-font-performance-results.csv)、[最终源码/API 清单](architecture-inventory-final.json)。此前的[源码架构审计](architecture-performance.md)和[完整帧基线](frame-performance.md)保留改造前证据。

1k 的 `custom-attribute` 同时执行旧 JS view 和逐项 setAttribute，沿用基线单独负载；没有扩展到 10k/100k。字体矩阵复用同一字体、尺寸、字符串长度及裁剪；host-effect 额外增加一层宿主字形效果，因此不等价于纯 Native 文本的绘制工作量。
