## 原生迭代器

`test/native/property-iterator-transfer.cc` 链接当前包现有的原生对象文件，
使用真实 `AllPropertiesIterator` 和 `PropertiesIteratorView`。
程序观察实际分配对象的释放次数，不修改生产代码的私有字段。
链接器只保留该消费路径使用的原生代码。

| 原始清单索引 | 契约 | 实测 |
| --- | --- | --- |
| 2076 | `UniquePtr<AllPropertiesIterator>` 构造 | 转移所有权，读取实际属性，结束后释放一次 |
| 2077 | 移动构造 | 保留当前位置和属性引用，移出对象销毁不重复释放 |
| 2078 | 移动赋值 | 返回目标引用，立即释放旧对象一次，新对象由目标释放一次 |

编译检查同时验证不可复制和无异常移动声明。
3 个原生场景通过，源码通过 clang-format 和 cpplint。

JS 的 `iterateLocalProperties` 在一次原生调用内完成创建、遍历、复制和销毁，
返回有序的独立 `[name, Property]` 数组。关联运行场景实测入口数为 1、
反向回调数为 0；修改副本不改变元素属性，修改样式或销毁元素不损坏已有副本，
失效元素再次查询会报错。JS 不持有原生迭代器状态，因此不增加移动包装类。
