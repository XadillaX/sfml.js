# Core nineteen-criterion review

The exact Core/dependent declaration provenance is reconciled locally. All nineteen managed Core criteria are observed locally; renderer, platform, applications and independent whole-change acceptance remain separate.

[Exact declaration references](core-operation-acceptance.json) retain 2,096 unique sites: 549 Core and 1,547 dependent records. Of these, 2,094 match the original 3,926-declaration compiler inventory. Two conversion operators remain explicit source supplements without fabricated inventory indices.

The completed runtime evidence covers 135 files with 1,323 literal PASS lines and zero failed files. Composition: One complete 135-file runtime runner.

The Native event reference and binding comparison each contain eight matching observations. Fourteen private/opaque forward sites remain native type boundaries. Twenty-four Factory forward references point to their actual definitions or managed adapters without accepting type members.

Source, consumer and log paths are deduplicated and fingerprinted. Historical input maps and the recovered ledger retain their original bytes. References alone do not establish per-overload behavior.

## Public type-contract evidence

A19 resolves all 963 public callable signatures to real consumer calls. All ten internal signatures have actual source allocation calls and are explicitly excluded from public construction examples. Source and emitted declarations use structurally matched parameter/return types; there are no unmatched consumer signatures.

[Positive consumers](consumer-overload-coverage.json) retain exact source signatures and call sites. [Negative consumers](consumer-negative-contracts.json) record one mutation anchored to each resolved public signature: replacing its first argument with an unbranded Symbol, or supplying one to a zero-argument call. All 963 are rejected with actual TS2345, TS2554, TS2559 or TS2769 diagnostics. Eighteen checks were repeated individually to remove interference from overlapping/nested calls. Original consumer fixtures have zero diagnostics and retain their separately authored negative cases. Compiler mutations changed only in-memory source.

This evidence is bounded to those observed valid and invalid usages. It does not establish exhaustive runtime behavior for every upstream declaration or replace independent review. Renderer, platform, applications and whole-change acceptance remain open.

[Machine-readable evidence](core-19-evidence.json) lists exact selected scenarios, raw logs, fingerprints and remaining gates. All review here is implementer-only macOS arm64 evidence.
