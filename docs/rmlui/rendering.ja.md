# RmlUi 描画と Retina

RmlUi のレイアウトとジオメトリはネイティブバックエンドに保持されます。SFML が頂点バッファ、テクスチャ、シェーダー、描画先を管理します。ランタイムの全期間で同じ開いた `RenderWindow` を使用します。

描画器の作成には SFML のシェーダー対応と六つの必須プログラムが必要です。
未対応またはコンパイル失敗時は登録・選択前に例外を送出します。
ジオメトリやクリップマスクの転送失敗は UI フレームを中止し、ホストビューを復元します。
結合バッファだけの確保失敗は個別描画へ戻り、送信順を保持します。

## フレームを合成

ウィンドウのクリア、SFML シーンの記録、`window.flush()`、RmlUi コンテキストの描画、`window.display()` の順で実行します。flush は UI より先にシーンのコマンドを送信します。描画前の `context.update()` でレイアウト、アニメーション、表示密度を適用します。

`context.render()` は透明な UI 基本レイヤーを所有し、描画走査が成功した後でホストシーンに合成します。成功時も失敗時もホストの `View` とアダプター状態を復元します。コールバック例外では現在の UI フレームを破棄します。描画コールバックからウィンドウを読むと送信済みのホストシーンが見え、UI ピクセルはフレーム完了後に表示されます。

コンテキストフレームとオフスクリーンレイヤーは検証済みの八ビットステンシルを所有します。フレーム外で `RenderManager` からウィンドウへ直接描画する場合は `settings.stencilBits: 8` を指定します。

レイヤー零は合成元と合成先の両方に使え、自己合成とアルファマスク保存も可能です。コンテキストフレーム内では RmlUi の内容だけを含み、フレーム外の管理操作ではホストウィンドウを表します。予備レイヤーは同じサイズの最大八個、32 MiB の保存予算内で保持し、リサイズ時に旧サイズを解放します。

## 物理ピクセルと `dp`

macOS の `initialise(window)` は画面上のサイズを維持して Retina サーフェスを有効にします。以降、ウィンドウサイズ、マウス／リサイズイベント、テクスチャキャプチャは物理ピクセルです。初期化**後**の `window.getSize()` からコンテキストを作成します。

| 密度 2 の場合 | 結果 |
| --- | --- |
| 画面上の 1024 × 768 ウィンドウ | 2048 × 1536 のフレームバッファとコンテキスト |
| `font-size: 20dp` | 40 物理ピクセル。見かけのサイズを維持 |
| `font-size: 20px` | 20 物理ピクセル |
| マウス入力 | 再度倍率を掛けず、そのまま転送 |

コンテキストは更新時に `densityIndependentPixelRatio` を取得します。`processEvent` がリサイズを処理します。`context.dimensions` はキャッシュされた読み取り専用ビューです。ネイティブレイアウトの変更には `setDimensions(width, height)` を使います。

`initialise(window, { highDpi: false })` は、有効化済みを含む現在のサーフェス状態を保持します。一度有効になると `shutdown()` 後も、ウィンドウを閉じるまで維持されます。他のプラットフォームはバックエンドの密度値を使い、現在は 1 です。

## 描画対応範囲 {#renderer-coverage}

ビューポート、シザー、所有マスク、行列、保存・復元は
[描画状態](./render-state.ja.md)を参照してください。

| 機能 | 現状 |
| --- | --- |
| 文字、テクスチャ、単色ジオメトリ、矩形クリップ | 実装済み |
| ステンシルマスク、角丸の overflow クリップ | 実装済み。ステンシルバッファが必要 |
| オフスクリーンレイヤーと合成 | SFML RenderTexture で実装 |
| ぼかしとドロップシャドウ | SFML Shader で実装 |
| レイヤーのアルファマスク保存 | 実装済み、シザー領域の元の位置を保持 |
| 線形・放射・円錐・繰り返しグラデーション、creation | 全停止点と同次変換を保持するネイティブプログラム |
| CSS 画像マスク | 実装済み。macOS の前景／背景／マスク組み合わせを GL3 と比較済み |
| 不透明度、明るさ、コントラスト、反転、グレースケール、セピア、色相回転、彩度 | ネイティブの乗算済み色シェーダーで実装 |
| 背景フィルター | macOS で読み取り可能な UI 基本レイヤーと CSS 組み合わせを検証済み |
| ジオメトリとクリップの 4×4 変換 | ネイティブの同次投影、Z クリップ、透視補正テクスチャ補間 |

[VisualTests ランチャー](../../packages/sfml.js-rmlui/examples/README.ja.md#visual-tests)は上流ページのプレビューです。クラッシュせず読み込めても、視覚的なアサーションの成功や完全な描画対応を保証しません。

色フィルターはリスト順に実行します。
`RenderManager.compileFilter(name, { value })` のネイティブ名は
`opacity`、`brightness`、`contrast`、`invert`、`grayscale`、`sepia`、
`hue-rotate`、`saturate` です。色相角度はラジアン、値の省略時は 1 です。
明示的な値は有限の数値である必要があります。行列は乗算済みアルファと
透明ピクセルを保持し、反転と不透明度を 0–1 に制限します。
固定 GL3 と同じく、行列出力は RGBA8 チャネル範囲で制限し、
元のアルファ値では制限しません。読み込み、生成、事前読み込み、レイヤー保存の
通常テクスチャは線形フィルターとリピートを使い、0–1 外の UV も繰り返します。
効果シェーダーが使用できない場合、コンパイル結果は無効なハンドルです。

`blur` は `{ sigma }` を使い、省略時は 1 です。有限の非負の物理ピクセル値が
必要です。大きい半径は固定 GL3 の段階的な半分縮小と七点ガウス核を使い、
二の累乗で安定した位置に拡大します。シザー外のサンプルは透明です。
縮小後にサンプルが残らない領域も透明になります。

`drop-shadow` は `{ sigma, offset, color }` を使います。sigma は 0、
offset は `{ x: 0, y: 0 }`、色は不透明な黒が初期値です。移動量は有限の
物理ピクセル値で、正の Y は下向きです。色は未乗算 RGBA バイトです。
元のアルファを移動して着色し、必要ならぼかし（sigma ≥ 0.5）、
変更していない元画像を影の上に合成します。フィルターは順に処理し、
三つの SFML 一時ターゲットを再利用して乗算済みピクセルと元レイヤーを保持します。
macOS ネイティブテストは奇数寸法の全面／シザー付き 16 画像を公式 GL3 と比較し、
透明境界、元レイヤーの保持、小数／負の移動量とターゲット再利用も検証します。

十個の実際の RML/CSS シーンで前景・背景フィルター、グラデーションマスク、
全組み合わせ、変換付き角丸クリップを検証します。macOS の GL3/SFML 比較は
RGB 最大誤差 2 以下、平均誤差 0.1 以下を要求します。繰り返しと逆順描画は同じピクセルを
保持し、乗算済みアルファと透明な隅も検証します。十二のネイティブ分配テストは
基本・追加レイヤー、一時ターゲット、キャプチャの失敗と再試行を確認します。
マスク記録の分配失敗時もキャプチャ済みテクスチャを解放します。
アプリケーションと VisualTests 全体の検証は別に行います。

ジオメトリとクリップマスクは完全な列優先行列を共有します。平行移動は行列変換に
先行し、左上原点の物理ピクセル投影と −10000～10000 の Z 範囲を使用します。
マスクは定義時の書き込みシザーと変換を保持し、重複三角形でも論理的な交差を
維持します。八ビット値が尽きる前に正規化します。独自の `vertex_shader` は
指定された頂点プログラムと SFML のアフィン変換規約を維持します。

## グラデーションと creation の引数

`RenderManager.compileShader` の `linear-gradient` は `p0` と `p1`、
`radial-gradient` は `center` と正の `radius`、`conic-gradient` は
`center` とラジアンの `angle` を使います。ローカルピクセル UV、省略時 false の
`repeating`、タグ付き `color_stop_list` を使用します。停止位置は有限かつ
非減少の `Unit.NUMBER`、色は乗算済みバイトです。GL3 の逐次 `smoothstep`
で全停止点を混合し、16 個を超えても保持します。全リストを GLSL に組み込み、
GPU コンパイル失敗時は無効なリソースを返します。

単一停止点は単色、同じ位置はその位置で後の色に切り替わります。繰り返しは
最初と最後の位置で折り返し、幅が零なら最後の色です。空・降順リスト、
一致する線形端点、非正半径、非有限引数は無効です。円錐中心の座標は零です。

creation は `shader` 名と `{ value: 'creation', dimensions: { x, y } }` を使い、
寸法は有限の正数です。正規化ローカル UV と `SystemInterface` の経過秒数で、
固定版 GL3 の RGB 式と頂点アルファを保持します。中心距離と逆数分母の下限は
`1e-6` です。組み込み効果は完全な 4×4 変換を使い、任意のテクスチャを無視します。
明示的な `vertex_shader` と `fragment_shader` は独自 GLSL 拡張を選択し、
SFML のアフィン座標規約を使用します。

## 密度の検証

`packages/sfml.js-rmlui` で `npm test`、macOS では加えて `npm --prefix ../sfml.js-interop run test:high-dpi` を実行します。1×／Retina のレイアウト、文字のラスタライズ、ヒット判定、リサイズ、物理ピクセルのキャプチャ、サイズ制限を検証します。物理モニター間の移動は実機検証が必要です。
