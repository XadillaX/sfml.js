RenderWindow · CircleShape · Color

最初の SFML ウィンドウ。

RenderWindow を作り、CircleShape を描いてフレームを表示します。SFML がウィンドウと描画を、JavaScript がループを担当します。TypeScript の型定義も同梱しています。

クイックスタートへ

デスクトップのグラフィカル環境で実行してください。Esc で終了します。setImmediate によりフレーム間で Node.js の I/O を処理できます。

JS hello.cjsnode hello.cjs
const sf = require('sfml.js');
const win = new sf.RenderWindow(
  new sf.VideoMode(new sf.Vector2u(800, 600)),
  'Hello, sfml.js',
);
const circle = new sf.CircleShape({ radius: 80 });
circle.setPosition(new sf.Vector2f(320, 220));
circle.setFillColor(new sf.Color(108, 190, 82));
win.setFramerateLimit(60);

function frame() {
  win.handleEvents({
    Closed: () => win.close(),
    KeyPressed: e => {
      if (e.code === sf.Keyboard.Key.Escape) win.close();
    },
  });
  if (!win.isOpen()) return;
  win.clear(new sf.Color(24, 28, 32));
  win.draw(circle);
  win.display();
  setImmediate(frame);
}
frame();
