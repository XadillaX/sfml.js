サンプル ​

このリポジトリのサンプルはルートディレクトリで実行します。初回実行前に npm ci、ソースコードの変更後に npm run build を実行してください。グラフィックスのサンプルには、利用可能なディスプレイサーバーと OpenGL ウィンドウのサポートが必要です。公式 Vulkan サンプルは Vulkan で描画しますが、sf.Window は描画に使わない OpenGL コンテキストも作成します。

プロジェクトトップ · クイックスタート · 開発ガイド

ここから始める ​

sh
node examples/breakout.cjs
node examples/all-types.cjs --frames=120
node examples/render-texture.cjs --frames=120
node examples/network.cjs

ビルド済みの場合はスクリプトを直接実行してください。npm run demo:* は package.json に従って再ビルドします。グラフィックスの各入口が対応するフレーム数、フォントなどの引数は、それぞれのスクリプトを基準とします。

ブロック崩しで遊ぶ ​

breakout.cjs は衝突判定、3 つのライフ、スコア、勝敗判定を備えたゲームです。左右キーまたは A／D で移動、Space で発射または再開、P で一時停止、Esc で終了します。操作中にフォーカスを失うと一時停止します。

npm run demo:breakout でビルドして起動できます。macOS／Linux では次のコマンドで同じゲーム画面を撮影できます。

sh
SFML_DEMO_SNAPSHOT=/tmp/sfml-breakout.png \
  node examples/breakout.cjs --autoplay --frames=900

最後のフレームの実際の描画結果を保存します。--autoplay はパドルを自動操作し、--frames は実行フレーム数を制限します。node examples/breakout.cjs --self-test はウィンドウを開かずにゲームロジックを検証します。

継続的に描画するサンプルの多くは Esc で終了できます。--frames=120 を渡すと実行時間を制限できます。text サンプルでは --font=/path/to/font.ttf と --text=中文示例 でフォントとテキストを指定します。中国語には対応するグリフが必要です。

一部の診断用サンプルは、リポジトリ内部のプレビューや検証用ヘルパー関数を使います。アプリケーションの入門には、公開インターフェースだけを使うクイックスタートのウィンドウコードを利用してください。

オーディオとネットワーク ​

ファイルデモの内容
audio.cjsSound、Music、Worker によるデータ供給、エフェクト、録音再生
audio-worker.cjsオーディオサンプルが読み込む tone と filter の Worker ファクトリー

audio サンプルでは、1～4 でモードを切り替え、Space で再生／一時停止、S で停止、E でエフェクトを切り替え、R／T で録音を開始／終了します。矢印キーでパンと音量を調整します。録音はシステムのマイクを使い、通常起動ではキー入力を待ちます。

スクリーンショット ​

SFML_DEMO_SNAPSHOT に対応するグラフィックスのサンプルは、実行画面を保存できます。macOS／Linux では、たとえば次のように実行します。

sh
SFML_DEMO_SNAPSHOT=/tmp/sfml-render-texture.png \
  node examples/render-texture.cjs --frames=2

PowerShell の場合：

powershell
$env:SFML_DEMO_SNAPSHOT = "$env:TEMP/sfml-render-texture.png"
node examples/render-texture.cjs --frames=2
Remove-Item Env:SFML_DEMO_SNAPSHOT

総合サンプルの all-types は PPM で保存し、他のサンプルの保存形式はそれぞれの入口の実装に従います。静止画のスクリーンショットが示すのは、指定したシーンの描画結果だけです。スループット、音声出力、入力デバイスのテスト結果を示すものではありません。

ゲームプロジェクト ​

node-sfml-demos ​

node-sfml-demos には、sfml.js で実装した Bomberman、Breakout、Tetris、Doodle Jump、Arkanoid が含まれています。

プロジェクトを置くディレクトリで、この独立したリポジトリをクローンしてください。各ゲームのディレクトリで依存関係をインストールし、起動します。Bomberman の場合：

sh
git clone https://github.com/XadillaX/node-sfml-demos.git
cd node-sfml-demos/bomberman
npm install
node index.js

ゲームごとのディレクトリ、操作方法、元の C++ ソースコードはリポジトリの READMEを参照してください。ネイティブビルドの要件も適用されます。

ClojureScript で遊ぶ 16 ゲーム ​

16-sfml.js-games-ported は jsyqrt/games のフォークです。元の 16 ゲームは C++ と SFML で作られています。このフォークでは全作品を ClojureScript と sfml.js に移植し、元のディレクトリ構成、素材、ゲームロジック、操作方法を保持しています。

nbb を使って Node.js 上で実行するため、JVM や個別のコンパイルは不要です。プロジェクトを置くディレクトリにゲームリポジトリをクローンし、そのルートから起動してください。

sh
git clone https://github.com/XadillaX/16-sfml.js-games-ported.git
cd 16-sfml.js-games-ported
npm ci
npx nbb "01 Tetris/main.cljs"

Node.js 20.5 以降、ネイティブビルドの要件を満たす環境、OpenGL ウィンドウに対応するグラフィカルセッションが必要です。依存関係は sfml.js@1.0.0-rc.2 と nbb@1.6.214 に固定されています。各スクリプトは自身のディレクトリを基準に素材を読み込みます。

SFML 公式サンプル ​

official/ には SFML 公式リポジトリから移植した 24 サンプルがあります。テニス、シェーダー、テキスト、地形、音声、通信、X11、OpenGL ウィンドウ、SFML／OpenGL 混在描画、Vulkan、Cocoa と Win32 の連携を含み、元のシーンと素材を保持しています。操作方法、Node 向けの調整、出典、ライセンスはガイドを参照してください。未移植は android のみです。

sh
node examples/official/tennis/Tennis.cjs

Vulkan は x64 の Linux／X11 と Windows 向けで、nvk 0.8.0、Vulkan ローダー、4 倍の異方性フィルタリングに対応するドライバー・デバイスを使います。SFML はウィンドウ、イベント、サーフェスを担当し、nvk が独自のネイティブブリッジなしで Vulkan を直接呼び出します。SFML Graphics は引き続き OpenGL を使います。SFML の Vulkan 連携はコンパイル時に macOS 非対応となるため、MoltenVK の導入だけでは有効になりません。Linux／X11 と Windows のネイティブ描画と操作はどちらも検証済みです。操作と要件はプラットフォーム連携を参照してください。

sh
cd examples/official
npm ci --prefix vulkan --ignore-scripts
node vulkan/Vulkan.cjs

旧バージョンのサンプル ​

ported/ には元の 16 本のスクリプトを保持しています。14 本は現在の API で動作し、2 本は旧版の非同期描画インターフェースに依存しており、未対応を報告します。

sh
npm run demo:ported

all-types-scene.cjs と bitmap-label.cjs はデモの補助ファイルであり、独立したアプリケーションの入口ではありません。
