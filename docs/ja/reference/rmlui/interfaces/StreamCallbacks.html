    StreamCallbacks

    Rml::Stream 仮想メソッドの同期実装。

    補足

    メソッドは一度取得します。read と peek は独立配列、write は コピーを受け取ります。正確な数値か真偽値を同期で返してください。 ネイティブ API の再入は禁止です。循環参照も GC が回収できます。

    interface StreamCallbacks {
        peek?: (output: Uint8Array, count: number) => number;
        popBack?: (length: number) => number;
        popFront?: (length: number) => number;
        pushBack?: (input: Uint8Array, count: number) => number;
        pushFront?: (input: Uint8Array, count: number) => number;
        close(): void;
        isEOS(): boolean;
        isReadReady(): boolean;
        isWriteReady(): boolean;
        length(): number;
        read(output: Uint8Array, count: number): number;
        seek(offset: number, origin: SeekOrigin): boolean;
        tell(): number;
        truncate(length: number): number;
        write(input: Uint8Array, count: number): number;
    }

    プロパティ

    オプションpeek

    peek?: (output: Uint8Array, count: number) => number

    位置を進めない任意の読み取り。既定は read 後に seek で戻します。

    型宣言

      • (output: Uint8Array, count: number): number

      • 独立した一時領域に読み込み、カーソルを進めます。

        引数

        output
        Uint8Array

        一時バイト列。バッファの切り離しやサイズ変更は禁止です。

        count
        number

        最大読み取りバイト数。

        戻り値

        number

        [0, count] の整数。
