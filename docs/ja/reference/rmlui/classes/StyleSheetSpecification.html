    StyleSheetSpecification

    ランタイムのグローバル RCSS レジストリ Rml::StyleSheetSpecification。

    補足

    初期化と終了は RmlUi ランタイムに従います。文書を読む前にカスタム属性を登録します。 組み込み定義は読み取り専用で、カスタム定義は終了まで変更可能です。

      カスタム Rml::StyleSheetSpecification 属性を登録します。

      引数

      string

      組み込み属性や短縮形と重複しない一意な名前。

      string

      boolean

      boolean = false

      PropertyDefinition

      変更可能な定義。重複するカスタム名は元の定義を保持します。
