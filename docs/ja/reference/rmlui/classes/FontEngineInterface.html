    FontEngineInterface

    共有値と任意のホスト仮想関数を持つネイティブフォントインターフェース。

    補足

    選択したエンジンのみ操作可能です。Core がライフサイクルを管理し、 構築時に provider は起動しません。既定のグリフとアトラスは C++ で処理し、 カスタム仮想関数は同期ホストコールバックとして実行します。
