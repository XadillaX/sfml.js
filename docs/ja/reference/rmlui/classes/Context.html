    Context

    1 つの sfml.js 描画ウィンドウに紐付く RmlUi コンテキスト。

    補足

    登録済みは createContext、独立した所有インスタンスは Factory.instanceContext で取得します。追加した文書をコンテキストが所有し、 Context.remove または shutdown 後は関連ラッパーを使用できません。

    processEvent

    • processEvent(event: Event<(keyof EventPayloads)> | EventData): boolean

      sfml.js のウィンドウイベントを RmlUi に転送します。

      引数

      event
      Event<(keyof EventPayloads)> | EventData

      sfml.js のイベントオブジェクトまたはイベントデータ。

      戻り値

      boolean

      上流の伝播または操作の結果。無視するイベントでは true。

      補足

      キー・テキスト・ホイールは伝播状態、マウス・タッチは要素と操作していないかを返します。 座標は物理ピクセルです。キー修飾はイベントのスナップショット、ポインター修飾は現在の状態です。 タッチは 1 要素の TouchList に変換します。システムキーは macOS で LMETA/RMETA、 他で LWIN/RWIN です。TextEntered は CR を LF に変換し、他の制御文字を除外します。 リサイズで寸法と密度も更新します。

      ソースと継承
