    ElementStyle

    ネイティブカスケードと変更状態を保持する要素所有の Rml::ElementStyle。

    補足

    クラス・擬似クラスの変更後は updateDefinition を明示的に呼びます。 取得値は所有コピーです。高頻度数値処理は共有コマンドを使い、配置計算は ネイティブで実行します。要素破棄・ランタイム終了後は無効です。

    computeValues

    • computeValues(
          values: ComputedValues,
          parentValues: null | ComputedValuesView,
          documentValues: null | ComputedValuesView,
          valuesAreDefaultInitialized: boolean,
          dpRatio: number,
          viewportDimensions: VariantVector2,
      ): Set<PropertyId>

      所有値へ計算し要素の実際の変更集合を消費します。

      引数

      values
      ComputedValues

      この要素に関連する書き込み可能な値。

      parentValues
      null | ComputedValuesView

      計算済み親要素の値または null。

      documentValues
      null | ComputedValuesView

      計算済み文書の値または null。

      valuesAreDefaultInitialized
      boolean

      出力がネイティブ既定値のままか。

      dpRatio
      number

      有限の正の密度比率。

      viewportDimensions
      VariantVector2

      有限のネイティブ視口寸法。

      戻り値

      Set<PropertyId>

      消費した変更 ID を返し、継承依存を子へ伝えます。

      補足

      親から子の順で実行します。配置は更新しません。次の Context.update 前に 返された全 ID を dirtyProperty で変更済みにしてライブ配置へ適用します。
