    StringUtilities

    UTF-8 バイト位置とコードポイントを使う Rml::StringUtilities。

    補足

    ASCII、RML 実体、引用符は原生規則です。索引には StringView を再利用します。

    静的expandString

    • expandString(
          value: StringInput,
          delimiter?: string,
          quoteOrIgnore?: string | boolean,
          unquote?: string,
          ignoreRepeatedDelimiters?: boolean,
      ): string[]

      任意の開始・終了引用符でネイティブリストを展開します。

      引数

      value
      StringInput

      リストのテキスト。

      delimiter
      string = ','

      ASCII 区切り文字。既定はコンマです。

      quoteOrIgnore
      string | boolean = false

      開始引用符または連続区切りの省略指定。既定は false です。

      unquoteオプション
      string

      独自引用符の終了文字。開始引用符指定時は必須です。

      ignoreRepeatedDelimiters
      boolean = false

      独自引用符で内部の空項目を省略。既定は false です。

      戻り値

      string[]

      ネイティブ展開項目。既定の引用符は除去されます。
