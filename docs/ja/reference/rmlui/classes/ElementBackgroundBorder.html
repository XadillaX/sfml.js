    ElementBackgroundBorder

    要素所有の検証付き Rml::ElementBackgroundBorder。

    補足

    トークンは分離要素を保持し、破棄・終了で無効になります。効果関数内の描画と ジオメトリ変更はネイティブ部品の変更前に拒否します。

    getClipGeometry

    • getClipGeometry(area: BoxArea): Geometry

      GetClipGeometry を所有ジオメトリにコピーします。

      引数

      area
      BoxArea

      Border・Padding・Content。Margin と Auto は拒否します。

      戻り値

      Geometry

      独立したネイティブジオメトリ。管理器がなければ空です。

      補足

      部品再生成・要素破棄後もコピーは有効です。解放・変更は部品に影響しません。 管理器が寿命を制御しますが、getMesh() のコピーは管理器解放・終了後も使えます。

    render

    • render(): void

      この要素の背景・境界・ボックス影をネイティブ描画します。

      戻り値

      void

      補足

      現在の計算スタイル・配置・管理器状態を使います。先に視口を準備します。 管理器がない分離要素は描画せず、別管理器の活動レイヤーと関数再入を拒否します。
