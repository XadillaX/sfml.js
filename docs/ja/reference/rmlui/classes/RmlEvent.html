    RmlEvent

    RmlUi イベントのコピー。ネイティブ伝播制御は現在のコールバック中のみ有効。

    補足

    各リスナーは投影座標を含む独自のコピーを受け取ります。保存した項目は読めますが、 コールバック終了後の伝播状態取得と停止操作は例外になります。id はイベントの種類です。

    getParameter

    • getParameter<const T extends VariantConversionDefault>(
          name: string,
          defaultValue: T,
      ): VariantResult<T>

      Rml::Event::GetParameter の型変換。ネイティブイベントが有効な間使えます。

      型パラメーター

      • const T extends VariantConversionDefault

        既定値で選択するネイティブ変換型。

      引数

      name
      string

      ネイティブパラメーター名。

      defaultValue
      T

      T を選ぶ非 null の所有 Variant。

      戻り値

      VariantResult<T>

      ネイティブ変換結果。パラメーターがなければ既定値。

      補足

      JS コピーと独立した投影済みパラメーターを読みます。number は double、 BigInt は int64、INT64_MAX を超える場合は uint64 を選択します。 非数値文字列の数値変換は 0。整数範囲外は例外です。 scriptinterface は保護された Element、Context、Event 参照を読み、 ネイティブ参照の期限が切れると null になります。 ベクトルと色はコピーです。値の保持には parameters を使います。

      ソースと継承
