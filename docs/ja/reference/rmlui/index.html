    API リファレンス

    sfml.js-rmlui · 概要

    初期化、フォント、イベント処理、フレーム描画。 RML の読み込み、要素のプロパティ、ネイティブの有効期間。 イベントデータのコピーと JavaScript リスナーのシグネチャ。

    ランタイムとコンテキスト

    初期化、フォント、イベント処理、フレーム描画。

    initialise

    SFML バックエンドのシステム・レンダーインターフェースで RmlUi を初期化。

    createContext

    名前付きの RmlUi コンテキストを作成します。

    Context

    1 つの sfml.js 描画ウィンドウに紐付く RmlUi コンテキスト。

    ネイティブ void* の格納と変換を選択する所有ホストオブジェクト。

    VariantReadValue

    不透明ポインターが参照する元のオブジェクトを含むネイティブ出力。 ネイティブ由来の値は再格納でき、任意のホストには voidptr が必要です。

    VariantResult

    既定値で選ぶ結果型。プリミティブのリテラル型は拡張されます。

    VariantScriptObject

    Native ScriptInterface の所有者が登録した元の JS オブジェクト。 コピーは保護された参照を保持し、拡張がネイティブ寿命を管理します。

    VariantScriptPointer

    保護された ScriptInterface 参照の格納値と GetInto の変換先。

    VariantValue

    対応する Rml::Variant 値。64 ビット整数は正確な BigInt になり、 Element、Context、Event の同一性を保持し、任意のポインターは拒否します。

    VariantVector2

    Rml::Vector2f の値。成分はネイティブ float 精度になります。

    VariantVector3

    Rml::Vector3f の 3 成分値。

    VariantVector4

    Rml::Vector4f の 4 成分値。
