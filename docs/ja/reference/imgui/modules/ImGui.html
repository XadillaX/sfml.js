    API リファレンス/ImGui名前空間

    ImGui

    インターフェイス

    FontTextureView

    アトラステクスチャデータのビュー。

    ImDrawCmdFields

    ネイティブメモリー上の描画命令値。スナップショットではありません。

    ImDrawDataFields

    フレーム描画の集計と表示・フレームバッファ間の座標情報。

    ImDrawListFields

    描画リスト設定と内部ジオメトリー管理状態。

    ImDrawListSplitterFields

    分割・結合・切り替え呼び出しで管理する内部チャンネル状態。

    ImFontAtlasCustomRectFields

    アトラス配置結果。正規化 UV ではなく画素座標です。

    ImFontAtlasFields

    アトラス構築設定。構築前に編集し、フレームのロック中は変更しないでください。

    ImFontConfigFields

    アトラス構築時に使用するフォントソースとラスタライザーの設定。

    ImFontGlyphFields

    ライブなグリフ寸法、UV とネイティブのビットフィールドアクセサー。

    ImGuiInputTextCallbackDataFields

    テキストコールバック値。位置・長さは JS 索引でなく UTF-8 バイト単位。

    ImGuiIOFields

    コンテキスト設定と入出力状態。出力はネイティブ側が更新します。

    ImGuiListClipperFields

    クリッパーの出力範囲と内部の垂直位置管理状態。

    ImGuiMultiSelectIOFields

    複数選択の範囲起点とナビゲーション状態。要求リストは含みません。

    ImGuiPayloadFields

    ドラッグ＆ドロップのスカラーメタデータ。データポインターは含みません。

    ImGuiPlatformIOFields

    数値文字入力用のプラットフォームロケール設定。

    ImGuiSelectionBasicStorageFields

    選択ストレージの件数と順序設定。選択された ID 集合ではありません。

    ImGuiStyleFields

    ネイティブスタイル値。特記しない寸法は画素単位です。

    ImGuiTableSortSpecsFields

    テーブルのソート指定数とアプリ側のソート待ちフラグ。

    ImGuiTextFilterFields

    カンマ区切りフィルターの構築時に計算するテキストフィルター管理状態。

    ImGuiViewportFields

    ビューポート ID と表示座標形状。作業領域は予約済み UI を除きます。

    NativeStructMapping

    構造体アクセサーを構築するネイティブ領域とスカラー配置情報。

    SelectedItem

    選択項目の反復結果。

    型エイリアス

    DrawCallback

    DrawList のカスタム描画コールバック。

    FormatArgument

    書式付きヘルパーが受け付ける引数。

    ImDrawCmd

    描画リストまたは描画コールバックから借用する描画命令ハンドル。

    ImDrawData

    フレーム描画データ。借用した結果は次の NewFrame() で無効になります。

    ImDrawFlags

    パスと角設定のビット組み合わせ。

    ImDrawList

    命令と頂点バッファのハンドル。ウィンドウ所有のリストは現在のフレーム用です。

    ImDrawListFlags

    描画リスト設定のビット組み合わせ。

    ImDrawListSharedData

    ImGui コンテキスト内の描画リストが共有する借用設定。

    ImDrawListSplitter

    描画リストのチャンネルを分割・結合するヘルパーのハンドル。

    ImFont

    フォントハンドル。アトラスから借用したものはフォントのクリアで無効になります。

    ImFontAtlas

    ラスタライズ済みフォントのアトラス。コンテキストからの戻り値は借用です。

    ImFontAtlasCustomRect

    借用したアトラス矩形。矩形追加や再構築で無効になる場合があります。

    ImFontAtlasFlags

    フォントアトラス構築設定のビット組み合わせ。

    ImFontConfig

    フォント追加・構築時に使うフォントソース設定のハンドル。

    ImFontGlyph

    借用したグリフ寸法とアトラス座標。フォント再構築で無効になります。

    ImFontGlyphRangesBuilder

    両端を含むグリフ範囲を構築する Unicode 文字集合のハンドル。

    ImGuiBackendFlags

    バックエンド能力のビット組み合わせ。

    ImGuiButtonFlags

    ボタン設定のビット組み合わせ。マウスボタンは複数指定可能。

    ImGuiChildFlags

    子ウィンドウ設定のビット組み合わせ。

    ImGuiCol

    スタイル色枠の数値添字。

    ImGuiColorEditFlags

    色編集とプレビュー設定のビット組み合わせ。

    ImGuiComboFlags

    コンボ設定のビット組み合わせ。

    ImGuiCond

    設定適用の単一条件。

    ImGuiConfigFlags

    アプリ IO 構成のビット組み合わせ。

    ImGuiDataType

    ネイティブ格納型の数値識別子。

    ImGuiDir

    方向の数値識別子。

    ImGuiDragDropFlags

    ドラッグ＆ドロップ設定のビット組み合わせ。

    ImGuiFocusedFlags

    ウィンドウフォーカス照会設定のビット組み合わせ。

    ImGuiHoveredFlags

    ホバー照会設定のビット組み合わせ。

    ImGuiInputFlags

    ショートカット配送と反復設定のビット組み合わせ。

    ImGuiInputTextCallbackData

    テキスト編集コールバックの状態。呼び出し中のみ有効です。

    ImGuiInputTextFlags

    テキスト入力設定のビット組み合わせ。

    ImGuiIO

    コンテキストから借用した入出力状態。コンテキスト破棄後は無効です。

    ImGuiItemFlags

    共通ウィジェット設定のビット組み合わせ。

    ImGuiKey

    キー API が受け取る名前付き入力識別子または修飾ビット。

    ImGuiListClipper

    等間隔でランダムアクセス可能な行の表示範囲を求めるイテレーター。

    ImGuiMouseButton

    マウスボタンの添字。

    ImGuiMouseCursor

    カーソル形状の数値識別子。

    ImGuiMouseSource

    ポインター入力元の数値識別子。

    ImGuiMultiSelectFlags

    複数選択設定のビット組み合わせ。

    ImGuiMultiSelectIO

    現在の複数選択スコープから借用する選択要求と状態。

    ImGuiPayload

    借用したドラッグ＆ドロップのデータ。操作終了後は使わないでください。

    ImGuiPlatformIO

    ImGui コンテキストが所有するプラットフォームサービスとロケール状態。

    ImGuiPopupFlags

    ポップアップ設定ビットと一つのマウスボタン添字。

    ImGuiSelectableFlags

    選択項目設定のビット組み合わせ。

    ImGuiSelectionBasicStorage

    複数選択要求を永続 ID に適用する選択集合のハンドル。

    ImGuiSelectionExternalStorage

    アプリ側ストレージに複数選択要求を適用するアダプター。

    ImGuiSelectionRequestType

    選択要求の種類を示す数値。

    ImGuiSliderFlags

    スライダーとドラッグ設定のビット組み合わせ。

    ImGuiSortDirection

    ソート方向の数値識別子。

    ImGuiStorage

    ID をキーとするネイティブ値ストア。借用時の寿命は所有者に従います。

    ImGuiStyle

    寸法、色、ホバー規則を含む、コンテキストから借用したスタイル状態。

    ImGuiStyleVar

    スタックで変更するスタイル項目の数値識別子。

    ImGuiTabBarFlags

    タブバー設定のビット組み合わせ。

    ImGuiTabItemFlags

    個別タブ設定のビット組み合わせ。

    ImGuiTableBgTarget

    表背景層の数値識別子。

    ImGuiTableColumnFlags

    列設定または状態ビットの組み合わせ。

    ImGuiTableFlags

    単一の符号化寸法方式を含む表設定ビット。

    ImGuiTableRowFlags

    表の行設定のビット組み合わせ。

    ImGuiTableSortSpecs

    借用したテーブルソート状態。テーブル変更や新フレーム後は再取得します。

    ImGuiTextBuffer

    末尾にネイティブ NUL バイトを持つ、拡張可能な UTF-8 テキストバッファ。

    ImGuiTextFilter

    カンマ区切りの包含・除外フィルター。マイナス接頭辞は除外を表します。

    ImGuiTreeNodeFlags

    ツリーノード設定のビット組み合わせ。

    ImGuiViewport

    借用したビューポート形状。所有コンテキストとビューポートの存続中のみ有効。

    ImGuiViewportFlags

    ビューポート種別と所有者のビット組み合わせ。

    ImGuiWindowFlags

    ウィンドウ設定のビット組み合わせ。

    ImVec2Like

    x/y、タプル、または Float32Array の先頭 2 要素からコピーする入力。

    ImVec2Value

    通常の 2 成分値。ネイティブメモリーのライブビューではありません。

    ImVec4Like

    値としてコピーする 4 成分入力。色は通常 RGBA 順です。

    ImVec4Value

    通常の 4 成分値。色の場合は RGBA で、各チャンネルは 0 から 1 です。

    InputTextCallback

    InputText のカスタムコールバック。

    ItemGetter

    Combo と ListBox の項目取得コールバック。

    PlotGetter

    プロットの値取得コールバック。

    変数

    ImDrawFlags

    パス閉鎖と矩形の角選択。角丸には半径指定も必要。

    ImDrawListFlags

    描画リストのアンチエイリアスと頂点オフセット能力。

    ImFontAtlasFlags

    フォントアトラス寸法と任意の焼き込み資源。

    ImGuiBackendFlags

    プラットフォームと描画バックエンドが報告する能力。

    ImGuiButtonFlags

    InvisibleButton() のマウスボタンとナビゲーション設定。

    ImGuiChildFlags

    BeginChild() のサイズ、余白、ナビゲーション設定。

    ImGuiCol

    ImGuiStyle の色枠。PushStyleColor() にも指定できる。

    ImGuiColorEditFlags

    色編集、選択、プレビューの設定。表示方式とデータの RGB/HSV 形式は別。

    ImGuiComboFlags

    コンボのプレビューとポップアップ寸法。高さ方式は一つ選ぶ。

    ImGuiCond

    ウィンドウ設定を適用する条件。組み合わせず一つ選ぶ。

    ImGuiConfigFlags

    アプリケーションが設定する IO 構成フラグ。

    ImGuiDataType

    ネイティブの格納型。Bool と String はスカラーウィジェット非対応。

    ImGuiDir

    ナビゲーションと矢印描画に使う四方向。

    ImGuiDragDropFlags

    ドラッグ元、ペイロード寿命、ドロップ先の受け入れ設定。

    ImGuiFocusedFlags

    IsWindowFocused() の範囲。生入力の振り分けには IO 捕捉フラグを使う。

    ImGuiHoveredFlags

    ホバー照会の範囲、遮蔽の例外、時間設定。生入力の配送には IO 捕捉を使う。

    ImGuiInputFlags

    ショートカットの反復と配送設定。Route 方針は一つだけ選ぶ。

    ImGuiInputTextFlags

    テキスト入力のフィルター、編集、コールバック設定。

    ImGuiItemFlags

    PushItemFlag() で制御する共通ウィジェット動作。

    ImGuiKey

    キー、パッド、マウスの名前付き入力と組み合わせ用修飾ビット。 NamedKey_BEGIN 未満のネイティブ・旧キーコードは名前付きキーではない。

    ImGuiMouseButton

    マウスボタンの添字。ビットフラグではない。

    ImGuiMouseCursor

    要求するマウスカーソル形状。

    ImGuiMouseSource

    ポインターイベントの物理的な入力元。

    ImGuiMultiSelectFlags

    複数選択の操作、解除規則、対象範囲。

    ImGuiPopupFlags

    ポップアップの表示と照会設定。マウスボタンは添字で、一つ選ぶ。 既定は右ボタン。他のフラグを渡す際も右クリックなら明示する。

    ImGuiSelectableFlags

    Selectable() の選択、強調表示、ヒット判定設定。

    ImGuiSelectionRequestType

    アプリ所有の選択データへ ImGui が要求する変更の種類。

    ImGuiSliderFlags

    スライダーとドラッグの値変換、直接入力、範囲設定。

    ImGuiSortDirection

    表ソート指定の並び方向。

    ImGuiStyleVar

    PushStyleVar()/PopStyleVar() で一時変更するスタイル項目。

    ImGuiTabBarFlags

    タブバーの並び順、操作部品、幅不足時の方針。

    ImGuiTabItemFlags

    個別タブの選択、配置、終了動作。

    ImGuiTableBgTarget

    TableSetBgColor() の背景層。RowBg0 から CellBg の順で描画する。

    ImGuiTableColumnFlags

    列設定と TableGetColumnFlags() が返す読み取り専用状態。

    ImGuiTableFlags

    表の配置、装飾、操作設定。寸法方式は一つ。ソートは指定の通知のみ。

    ImGuiTableRowFlags

    TableNextRow() に渡す行の役割。

    ImGuiTreeNodeFlags

    ツリーノードの外観、判定領域、展開動作。

    ImGuiViewportFlags

    ビューポートのプラットフォーム種別と所有者の印。

    ImGuiWindowFlags

    Begin() のウィンドウ外観、操作、寿命の設定。
