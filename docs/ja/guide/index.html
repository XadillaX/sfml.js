sfml.js ドキュメント ​

このドキュメントは、現在のリポジトリの SFML 3.1.0 バインディングに対応しています。初めて使う場合は「クイックスタート」から読み、個々のメソッドのシグネチャを調べる場合は TypeDoc を参照してください。

はじめに ​

ドキュメント内容
クイックスタート依存関係のインストール、インポート方法の選択、最初のウィンドウの作成
基本概念値とリソースのコピー、読み込みの完了時点、draw が反映されるタイミング
API ナビゲーション5 つのモジュールが提供する機能
サンプル一覧リポジトリ内の完全なデモの実行

モジュール別ガイド ​

モジュール内容
Systemベクトル、角度、時間、入力ストリーム、Unicode、エラー処理
Windowウィンドウのライフサイクル、イベント、リアルタイム入力、OpenGL、Vulkan
Graphics画像、テクスチャ、スプライト、図形、テキスト、ビュー、描画
Audio再生、ストリーミングでのデータ供給、エフェクト、録音、エンコードとデコード
NetworkPacket、TCP／UDP、DNS、TLS、HTTP、FTP、SFTP

開発への参加 ​

開発ガイドでは、ビルド、テスト、ソースコードの構成、現在のドキュメント公開手順を説明しています。

メソッドのシグネチャとエクスポート一覧は src/index.ts とそのソースコメントを基準とします。上流の概念は SFML 3.1.0 C++ リファレンスを参照してください。JavaScript への適応、特に Node.js の非同期処理、メモリ、ネットワークの挙動は、sfml.js のガイドと TypeDoc を基準とします。
