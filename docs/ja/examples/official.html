SFML 公式サンプル ​

SFML 公式サンプル の JavaScript 移植です。グラフィックス、ネイティブウィンドウ、入力、音声、通信の 24 サンプルを収録しています。Android は未移植です。

全サンプル · ビルド要件

クイックスタート ​

リポジトリのルートで実行します。

sh
npm ci
cd examples/official
node tennis/Tennis.cjs

以下のコマンドは examples/official で実行します。各スクリプトが必要な素材を読み込みます。描画にはディスプレイと OpenGL ウィンドウのサポートが必要です。

一覧：グラフィックス · プラットフォーム連携 · 入力とイベント · オーディオ · ネットワーク

プラットフォーム連携 ​

サンプルプラットフォーム依存関係
Window／OpenGLmacOS、Linux、Windowsルートの npm ci で @wettstein/nodegl を導入
X11X11 を利用できる Linuxルートの npm ci で x11 と @wettstein/nodegl を導入
CocoamacOSnpm ci --prefix cocoa --ignore-scripts
Win32Windows x64、Node.js 20+npm ci --prefix win32 --ignore-scripts
VulkanLinux x64（X11）、Windows x64、Node.js 20+npm ci --prefix vulkan --ignore-scripts

nodegl のビルドには CMake、C++ コンパイラー、OpenGL 開発ライブラリ（Linux では libgl1-mesa-dev）が必要です。Vulkan には Vulkan ローダーと 4 倍の異方性フィルタリングに対応するドライバーも必要です。

実行画面サンプルと操作

Window

OpenGL ウィンドウで回転する 6 色の立方体

操作 · 枠のドラッグでサイズ変更、Esc またはウィンドウを閉じて終了

node window/Window.cjs

OpenGL

SFML の背景・文字と OpenGL のテクスチャ立方体を混在描画

操作 · マウスで立方体を移動、Enter で mipmap 切替、Space で sRGB 切替、Esc で終了

node opengl/OpenGL.cjs

Vulkan

Vulkan で描画する回転テクスチャ立方体

操作 · マウスで立方体を移動、枠のドラッグでサイズ変更、Esc またはウィンドウを閉じて終了

node vulkan/Vulkan.cjs

Cocoa

macOS のネイティブ操作部品と埋め込み SFML ビュー

操作 · Update または Enter で文字を更新、Visible で表示切替、ダイヤルで回転、Color で背景色、Up／Down で拡大縮小。閉じる、Cmd+Q、Ctrl+C で終了

node cocoa/Cocoa.cjs

Win32

Windows のネイティブウィンドウに 2 つの SFML アニメーションと Quit ボタンを配置

操作 · Quit、ウィンドウを閉じる、または Ctrl+C で終了

node win32/Win32.cjs

X11

2 つの埋め込み SFML ウィンドウで立方体が異なる速度で回転

操作 · 任意のキー、ウィンドウを閉じる操作、Ctrl+C で終了

node X11/X11.cjs

ネットワーク ​

サンプルと操作実行
HTTP
リダイレクト対応の対話型 HTTP GET		node http/Http.cjs
FTP
対話型 FTP クライアント、ポート 21		node ftp/Ftp.cjs
SFTP
対話型 SFTP。ホスト指紋を確認してから認証		node sftp/Sftp.cjs
Sockets
TCP、TLS、UDP のメッセージ交換、ポート 50001		node sockets/Sockets.cjs
VoIP
TCP による音声録音、再生、リプレイ、ポート 2435		node voip/VoIP.cjs

sockets と VoIP は 2 つのターミナルで実行し、サーバーとクライアントをそれぞれ選択します。ローカル接続には 127.0.0.1 を指定してください。
