RmlUi サンプル ​

ネイティブ SFML ウィンドウで RmlUi 文書を実行します。カウンターから始めて、テーマ、移動可能なウィンドウ、テンプレート、視覚テストへ進みます。

前提条件 ​

すべてのコマンドは monorepo のルートで実行します。bootstrap は依存関係を導入し、各パッケージをビルドします。画面と OpenGL が必要です。macOS のビルドには Xcode Command Line Tools と CMake も必要です。クイックスタートを参照してください。

sh
node tools/bootstrap.cjs

RmlUi の TypeScript ソースを変更したら、npm run build:ts --prefix packages/sfml.js-rmlui を実行します。サンプルはローカルでビルドしたパッケージを使います。

ランチャーはパッケージの third_party/rmlui にある RmlUi 6.3 同梱素材を読み込みます。全項目を一覧表示するには：

sh
node packages/sfml.js-rmlui/examples/official.cjs --list

RML · RCSS

テーマと変数

テーマ切り替え、アクセントカラー、ホバースタイル

node packages/sfml.js-rmlui/examples/official.cjs variables

操作：1 はダーク、2 はライト、3 は高コントラスト、 R はランダムなアクセント、C はアクセントのリセットです。Escape で終了します。 ミッションボタンはホバー表示のみで、上流にはクリック処理がありません。

元のスタイルシートは固定の px 長を使います。 highDpi: false により Retina でも 1024 × 768 の フレームバッファーを保持し、上流のウィンドウサイズに合わせます。 F8 で Debugger を切り替え、Ctrl +/-/0 で Shell の表示密度を調整します。

上流のアプリケーション

公式 IME

元の十個のフォントを読み込み、ネイティブの入力欄とテキストエリアを開きます。

初回に五個の追加 Noto フォントを準備します（38 MB、SHA-256 検証）：npm run download:ime-fonts --prefix packages/sfml.js-rmlui。検証済みのキャッシュは再利用されます。

node packages/sfml.js-rmlui/examples/official.cjs ime

システムの入力方式を選び、入力欄にフォーカスします。Escape で終了します。

上流のアプリケーション

Invaders

元の C++ ゲーム、メニュー、デコレーターとハイスコアモデルを実行します。

node packages/sfml.js-rmlui/examples/official.cjs invaders

左右キーで移動、Space で発射、Escape で一時停止メニュー、F8 で Debugger を切り替えます。元のメニューから再開や終了を選択します。

先にパッケージをビルドしてください。ゲームモジュールは同じビルドディレクトリで生成され、読み込み時にコンパイラーは不要です。macOS は検証済み、Linux と Windows の実行は未検証です。

スコアはアプリのデータ領域に保存します。--scores-file /absolute/path/scores.txt は既存の親ディレクトリーを指定します。--frames 8 --exercise でフレーム数を制限して開始します。
